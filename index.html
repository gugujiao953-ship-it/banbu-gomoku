01

打谱

完整变化树、改着、候选点 A–E、节点注释与着法评价、谱内查找。从 2018 人机大战到 12,097 局 Gomocup，真实对局随手可研。

  • 变化树：创建分支 / 设主线 / 删除后续
  • 节点注释 · 局面文字 · 好手坏手评价

  • 三手胜 / 发阳论 / 坂田吾朗追诘胜等经典题集
  • AI 陪练：独立 Worker 应对，可强制停止
  • 题集文件夹 · 完成进度 · 错题本

大型棋谱引擎

1.2GB 的棋谱，装进口袋

网页版 RenLib WASM 核心在独立 Worker 中解析，软件层不设文件大小上限；分支与原生注释按当前局面实时查询，不再把整谱搬进内存。

  • 22,078,100 节点 松月.lib（131MB）完整解析成功；1,709 万节点标注谱浏览器导入后导航 P95 约 32ms。
  • 约 1.5 秒首屏 1.18GB 的斜月.lib 分页后端：标题与首批 25 万节点先行呈现，页面立即可操作。
  • 分支树可视化 当前路径附近节点成树展开，30%–10× 缩放，定位、书签、复制、重命名、删除一气呵成。
  • 原生注释保真 RenLib 节点文字（boardText）与 DP 局面标注按局面实时读取，69 万处标注不丢失。

AI 与分析

AI 在你的手机里思考

本地 Rapfi 分析推荐落点、胜率与主变化；VCF 强制胜搜索带独立证明校验；候选点按成五、活四、冲四、活三与防守点给出可解释排序。引擎不可用时明确回退标注，不伪造胜率。

可解释的每一步

AI 思考面板给出推荐点、胜率估计与 Top-3 候选；局面分析把「为什么走这里」拆成成五、活四、冲四、活三、防守点五项证据，而不是一句「AI 觉得好」。

  • VCF 强制胜搜索连续冲四推演，独立证明校验
  • 连珠禁手裁判长连 / 四四 / 三三，落子即判
  • 开局规则引擎五手两打、多打、塔十、塔拉交换

棋谱库与格式

几乎所有格式，都认得

本地棋谱库按名称、棋手、赛事即时检索，文件夹自由分组；导入导出覆盖 SGF 生态与 RenLib 二进制世界。

  • 按棋谱名、棋手、赛事即时检索
  • 文件夹自由分组，支持嵌套子文件夹
  • 批量处理：移动、删除、重命名
  • 回收站：删除的棋谱可恢复

导入

  • .sgf.fgf
    SGF FF[4] 游戏树UTF-8 / UTF-16 · 设置局面（AB/AW/AE/PL）· 过手 · 多顶层棋谱集合 · 注释、节点名、常用标记与着法评价 · 5–25 路方形棋盘
  • .lib
    RenLib 二进制变化树网页版 ReadLib / RenLib WASM 核心，独立 Worker 解析；软件层不设文件大小上限，分支与原生注释按局面实时查询
  • .db.dp
    DP / DB 局面数据库LZ4 压缩库：提取坐标记录、合并为变化树、保留节点文字，支持实时局面查询（已用九天指南真实验收）
  • .pos.txt
    坐标序列h8i8h9 / H8 I8 H9 形式的纯文本着法串，必须是完整坐标序列才接受
  • .ren.renjs.wzq
    SGF 语法变体内容为 SGF 语法时直接读取
  • .renju.json
    跨端数据格式本软件完整变化树（注释 / 标记 / 元数据）；也兼容带明确 moves 字段的落子列表对象
  • 图片
    图片识谱PNG / JPG / WEBP 棋盘截图：自动定位网格，识别棋子颜色与手数，完整序号可恢复落子顺序
  • 题库
    开宝兼容题集二维 JSON 题库：星级、空占位、A–O / 1–15 坐标与黑白尾码；内置 8 套 436 题

导出与备份

  • .sgf
    SGF 导出与 RenLib 及其他棋谱工具交换
  • .renju
    完整格式导出变化树、注释、标记与元数据全量保存，供三端互通
  • 备份
    一键备份 / 恢复棋谱库、题库、进度、草稿、设置与大型索引清单整包导出导入，恢复前完整校验
