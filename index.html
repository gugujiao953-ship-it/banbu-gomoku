03 / GENERATOR V3

题目不止一条标准答案。

VCF 生成器新增两个实验方向：多路汇合与错序岔路。它们让题目从直线计算，走向真正值得推敲的变化。

BEFORE · V1 快速旧版

看见一条杀路

经典单链式冲四路线，适合快速出题。

NOW · V3 多路汇合

不同次序，同一个杀点

多条正确冲四次序汇向同一终点。宣传片示例设为 3 资源、13 手、60 秒并启用烟雾弹，让读棋不只靠背一条路径。

V3 · 错序岔路 · 实验

首手唯一，错序也有后续。

错误的冲四次序不会立刻露出答案，而是走几手后才看出失败原因。生成器仍保留 v2 高质量推荐档与 v1 快速旧版，四档可按需要选择。

打谱不是只留下一串坐标。分支树、过手、通型跳转、棋谱库、识谱与引擎分析，把棋局真正变成可回看的研究材料。

NEW · PASS / TRANSPOSITION

过手，以及殊途同归。

过手（Pass） 不落子，手数 +1 并交换行棋方，同一局面可留住不同分支。遇到不同手序或旋转镜像后的同型局面，状态栏提示「同型 N」；点开选一处，直接跳转。

ENGINE · VISION · LIBRARY

从纸上、照片里，到棋盘上。
