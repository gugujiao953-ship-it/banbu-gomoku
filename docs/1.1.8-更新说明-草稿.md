## 半步五子棋打谱 v1.1.8

这是相对于 v1.1.7 的更新，聚焦图片识谱的准确性与速度、AI 引擎与分析的实战体验、移动端的导入与存储，并首次把网页版真正做成可以在 iPhone / iPad 上「添加到主屏幕」当本地应用使用的形态。

### 识谱准确性与速度

- **新增「识谱多核加速」并默认开启**（设置 →「可选增强功能」）：按设备的处理器核心数与可用内存自动开多个线程并行识别，把网格探测与逐格分析分摊到多核；生产包真实 UI 全流程实测从 6563ms 降到 2971ms（约 2.2 倍，12 核桌面），识别结果与单线程逐位相同（47 张语料逐位对照），遇到老设备或无法开线程的环境会自动回落单线程，关掉开关也能回到旧行为。
- **修复手机上「白子变黑子」**：印谱里空心白子的前景色统计到的是那圈深色描边，柔化或换设备后这项比例越过阈值，聚类输入被切成最暗四分位，白子就被判进了黑簇。修复后同一张真机谱图在 10 个柔化/变暗变体下颜色全部稳定（改前 1px 柔化即翻色），同时保证实心黑子不会被反向刷白。
- **导入进度会显示图片解码后的像素尺寸**，形如 `… · 89KB · 931×931`，方便一眼看出「同一张图在手机与电脑上结果不同」是不是因为传输时被重压或缩小了。
- **「复原手序」的序号识别继续增强**：采用渲染式识别并支持跨设备字体自适应，他机截图的序号复原能力明显提升，识别失败的图会诚实回退而不是给出错误手序。
- **修复识谱或 SGF 静态局面导入后「分析看的还是空盘」**：设置子现在会正确送进引擎，缺行棋方标记的局面也会按黑白子数推定先后手。

### AI 引擎与分析

- **强力引擎改为应用内下载官方冠军网络（NNUE）**：默认随包轻量引擎，在设置里一键下载约 40MB 的冠军网络，下载完成后下一次 AI 请求即生效，无需重启，也可删除恢复轻量；本版修正了此前的包格式问题，冠军网络自此才真正参与评估。
- **内置开局库（打点簿）**：内置索索夫-8 与山口五手两打两本打点簿，会按开局规则自动选用；命中开局线时 AI 按最强打点毫秒落子，未命中照常思考。人机对战弹窗和设置里都能单独开关，默认关闭。
- **AI 宣布五手打点数会随局面自适应**（不再固定 3 打）：开局越厚，宣布的点数越多，更接近正式比赛对「宣布方制衡黑棋」的要求。
- **分析面板升级为「持续 / 自对弈 / 提示」三模式**：持续分析越算越深、数字持续更新；自对弈可设每步时限、自动对下到五连；提示模式点一下直接为当前行棋方落一手，遇到杀棋立即落子。
- **引擎档位更细**：轻量 / 强力 / 自调三档，自调档可用滑杆在 128–2048MB 之间自由设定分析内存，高内存换取长分析下更深的搜索；分配失败会先降档重试再回落轻量并明确提示。
- **分析与对局更稳更快**：换手和落子后候选点几乎立刻出现、深度和节点只涨不跌、思考指示不再闪烁；点「停止思考」会先落 AI 当前算到的最强点，而不是掐掉回合空等。
- **分析面板更精简好读**：胜率统一标注为「黑方胜率」，候选点按行棋方视角显示并可点击展开该变化的最深预览图。面板小字提醒「本地棋力有限，胜率仅供参考」。

### 网页版与 iOS

- **可以直接在 iPhone / iPad 上把网页添加到主屏幕，当本地应用使用**：用 Safari 打开网页版 → 分享 → 添加到主屏幕，之后会以独立的全屏窗口启动（没有浏览器地址栏），首次联网打开过一次后即可离线使用。
- **补齐了 iOS 专属支持**：新增 `apple-mobile-web-app-capable`、状态栏样式、主屏应用名，以及三种尺寸的 `apple-touch-icon` PNG（由真实 Android 启动图标缩放并压平底色生成，避免 iOS 把透明区域当黑底），新图标会被 iOS 自己再做圆角遮罩。
- **网页版的 AI 引擎包需要应用内下载**：网页版本身不含引擎包，首次需要强力 AI 时会在应用内下载并缓存到浏览器；iOS Safari 对后台下载有回收策略，建议插电、连 Wi‑Fi 后一次性下完，详细步骤见 `docs/iOS-网页版说明.md`。

### 体验与界面

- **功能区布局编辑器**：打谱 / 读谱 / 做题的按钮可以自由拖拽摆放，内置「默认 / 简略」预设模板，每个功能区可一键整区隐藏；走棋导航拆成七个可独立摆放的按钮。
- **标注交互重做**：点已有标注一步取消（不再叠加覆盖），新增「去标注」擦除模式和「把本机标注写入棋谱」一键合入草稿。
- **做题体验重整**：做题里的「分析」永远是提示模式、算到杀棋立刻落子；应战时可以随时换边，重启题目会清空之前所有作答痕迹。
- **快捷中心支持自定义**：右上角「自定义」可勾选显示哪些条目，条目池扩展到覆盖棋盘显示、无障碍、数据与手册等更多设置，且「快捷中心有的设置，设置页里都有」。
- **打谱顶栏更紧凑**：打谱 / 读谱 / 做题三种模式切换移到顶部，退出类按钮收进状态栏右侧；主题列表改为一屏两列的卡片式；设置主目录图标加主题色并去重。
- **使用手册扩充到 19 章并配真实截图**，每章都有一步到位的「引导」按钮，把用户直接带到真实功能位置；首次进入还有 spotlight 式的新手导览。
- **每次版本更新后，首运行页会重新出现一次**：以前「看过就不再出现」的记录改成按版本号保存，升级到新版本时会再看到一次欢迎页（可以「先自己试试」，也可以「带我看看怎么用」进入新手导览）；关掉后写入当前版本号，同一版本内不再打扰。从 v1.1.7 及更早版本升级上来的用户同样会看到这一次。

### 导入导出、存储与更新

- **新增导出 RenLib `.lib` 与 PSQ**：SGF / JSON / LIB 之间互转会保留变化树与注释，PSQ / POS 只保留主线；原格式文件也能直接原样导出。
- **新增「导出并分享」**：把当前棋谱作为 SGF 文件直接交给系统分享面板，微信 / QQ 发出去对方打开即可打谱（对齐「导出即分享」的习惯）。
- **安卓导出位置更好找**：默认写入手机「下载」夹（设备不支持时退回「文档 / 半步五子棋打谱 / 导出」），也可以用系统文件夹选择器指定任意文件夹；设置「文件与存储」会显示当前占用空间。
- **安卓选图默认打开系统相册**：图片识谱点导入后直接停在相册，也可以在系统界面里切换到其他文件夹，不必再从「最近」一层层翻。
- **修复「检查更新」在手机上总是提示失败**：改为站点版本文件 → jsDelivr 镜像 → GitHub 兜底的多源链，并兼容四段构建号，正式包也能正确判断是否有新版本。

### 工程与发布

- 引擎包升级为 v3 官方布局（官方 `.bin.lz4` 数据，NNUE 冠军网络首次真正加载），页面 loader 必须与数据同版本成对发布；装过旧强力包的手机升级后会自动清理旧包并需重新下载。
- Android 的 WebView 缓存迁移键现在随版本号派生（本版为 `v118`），并有单测守住「改版本必须同步改 key」，避免新前端被旧缓存盖住。
- 多线程识别资产随引擎包一并下载，引擎包改为分片并发下载，构建产物不再把大型引擎包塞进 Service Worker 预缓存。
- 新增 3 条识谱回归门禁（多核结果逐位一致、空心白子颜色稳定、输入质量边界）与真机样本 fixture，防止白子翻色、多核不一致这类问题复发。

### 已知问题 / 未验证

- **序号匹配（复原手序）没有并行化**：它需要按手数顺序处理，语义上顺序相关，目前仍由主线程串行执行。
- **识谱多核加速的实际倍数只在 12 核桌面实测**（约 2.2 倍），手机上的真实提升尚未在真机验证。
- **iOS 未在真机验证**：构建链的兼容下限没有实测，建议 iOS 15 及以上；iOS 长时间不访问站点时可能清理站点数据，导致引擎包和本地记录丢失。
- **重度压缩或过小的图片仍可能掉子**：实测同一张谱图原图和 600px 缩放仍能全对，重度重压（如 q0.6）会丢序号、缩到 500px 以下开始出错、400px 可能掉 6–12 子，属已知质量边界。
