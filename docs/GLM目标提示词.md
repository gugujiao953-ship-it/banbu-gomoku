## 总目标

让网页版五子棋打谱工具在真实大型 RenLib .lib 上接近“爱五子棋”的体验：

1. 完整保留主线、所有分支、分支层级和相关标注。
2. 当前局面显示正确的直接后续变化点。
3. 走到分支末端可以找到同一分叉点的兄弟变化。
4. 每一步导航流畅，不能假死、丢点击、长时间无响应。
5. 分支面板使用虚拟列表、固定窗口或等价机制，不能一次性把十万级分支变成 DOM。
6. 已落子位置不显示后续变化标签。
7. 只显示当前局面相关的后续标签和明确属于当前局面的注释。
8. 去掉突兀的长方形标签框。
9. 彻底调查 ccc、黑点、白点、蓝点、c 的真实来源和含义，不能猜测硬编码。
10. 不能用“只显示前 N 个分支”掩盖解析不完整。

## 性能实现方向

请逐一排查并修复：

    Object.keys(document.nodes)
    Object.values(document.nodes)
    children.map/filter/forEach
    for...of children
    variationPreview
    findPositionMatches
    mainLineLength
    exportSgf
    每步候选分析
    render 中递归访问完整树

优先架构：

    文件
      -> Worker 解析
      -> 不可变紧凑索引
      -> 按 nodeIndex 查询
      -> currentNodeIndex 导航状态
      -> 局部棋盘/路径缓存
      -> 当前局面直接变化点
      -> 虚拟分支面板

分支面板不能只做“加载更多”后不断累积几万 React 行；优先使用虚拟列表或固定窗口。变化预览必须惰性计算、有缓存、有上限。
