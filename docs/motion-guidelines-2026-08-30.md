# 半步五子棋打谱轻量动效规范

日期：2026-08-30

## 目标

动效只用于解释状态变化和确认操作，不承担装饰性常驻展示。优先保证大棋谱浏览、低端 Android WebView、窄屏触摸和减少动态效果用户的稳定体验。

## 全局 Token

| Token | 当前值 | 用途 |
|---|---:|---|
| `--motion-fast` | 120ms | 按压、微提示、极短状态变化 |
| `--motion-normal` | 220ms | 普通落子、Toast、常规进入 |
| `--motion-emphasis` | 480ms | 最后一步聚焦、分支切换 |
| `--motion-result` | 900ms | 胜线绘制、结束状态入场 |
| `--ease-standard` | `cubic-bezier(.2,0,0,1)` | 普通状态变化 |
| `--ease-enter` | `cubic-bezier(.16,1,.3,1)` | 新元素进入与轻回弹 |
| `--ease-exit` | `cubic-bezier(.4,0,1,1)` | 离场与收起 |

## 使用规则

- 棋盘反馈优先使用 `transform`、`opacity`、SVG 描边和一次性 CSS 动画。
- 普通交互动画原则上不超过 300ms；强调动画不超过 500ms；结果展示不超过 1.2s。
- 不使用常驻 `requestAnimationFrame`、粒子系统、视频背景或大型动画库。
- 重复落子只重新挂载最后一步棋子图层，不重新挂载整张 SVG。
- 普通落子不触发整张棋盘闪光或遮罩，避免连续打谱时产生晃眼感。
- 导航和分支切换只创建一次性轻遮罩，不复制棋盘数组、不遍历大型数据库节点。
- 禁手动画只消费现有 `forbiddenReason()` 结果，不修改规则判定。
- AI 动画必须与 Worker 生命周期一致：完成、异常、取消或局面变化后立即停止。
- 静态状态必须独立可读，不能只依赖颜色或运动表达结果。

## Reduced motion

`prefers-reduced-motion: reduce` 下：

- 关闭落子缩放、棋盘闪变、胜线绘制、结果条入场、非法点扩散和 AI 点动画。
- 保留最后一步红点、完整胜线、结果文字、非法叉号和 AI 状态文字。
- 不通过延长动画替代关闭动画。

## 性能门禁

- 不新增运行时依赖和远程资源。
- 不新增图片、音频或 Lottie 包。
- `npm run build` 后 `dist` 必须继续低于 20MB。
- 窄屏浏览器回归必须覆盖落子、回退、分支、非法点、胜线、AI 状态和 reduced-motion。
- 页面控制台错误必须为 0。
