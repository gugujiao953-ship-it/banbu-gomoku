## 三、显示验收失败：文字仍是 7px

《雨》412×915 真实浏览器结果：


原因是 `src/styles.css` 同时存在两条规则：

```css
/* 前面 */
.renlib-variation-label { font-size:12px; ... }

/* 后面，覆盖前面 */
.renlib-variation-label { font:800 7px ui-monospace,monospace; ... }
```

GLM 回复所称的 12px 实际没有生效；即使 12px 生效，也低于用户刚刚明确提出的要求。

### 用户最新硬性要求

- 字体至少比当前大两倍多。
- 单字符接近一颗棋子的视觉大小可以接受。
- 单字符建议 **20–24px**，不是 10px 或 12px。
- 两字符建议 18–20px；三至四字符建议 14–17px。
- 原谱文字直接显示，不画圆框。

## 四、显示验收失败：black/white/blue 被 player 样式覆盖

## 六、建议的具体修复方式

### 1. 合并并清理 RenLib CSS

删除重复的旧 7px 规则，只保留一组集中定义。不要让 `player` class 决定 displayKind 点的颜色。

建议：

```css
.renlib-variation-label {
  font-family: ui-monospace, monospace;
  font-weight: 800;
  text-anchor: middle;
  dominant-baseline: central;
  paint-order: stroke;
  stroke: #fff9;
  stroke-width: 2.5px;
  pointer-events: none;
}

.renlib-text-single  { font-size: 22px; }
.renlib-text-double  { font-size: 19px; }
.renlib-text-compact { font-size: 15px; }
```

使用 `dominant-baseline:central` 后同步调整 SVG 的 `y`，不要继续固定用适配 7px 的 `y + 4`。

### 2. displayKind 必须高于 player

最稳妥的方案是：变化点显示时不再把 `player` 用作视觉颜色类；只由 `displayKind` 决定图形。若仍需保留 player 供辅助信息，颜色选择器必须互斥或确保 displayKind 规则最后出现且优先级更高。

必须增加明确的 neutral-dot 样式，不能让 neutral-dot 自动退化成黑棋/白棋颜色。

### 3. 按文字长度选择类

```tsx
const glyphCount = Array.from(display.displayText || "").length;
const sizeClass = glyphCount <= 1 ? "renlib-text-single"
  : glyphCount === 2 ? "renlib-text-double"
  : "renlib-text-compact";
```

不要把四字符文字全部截断后仍用同一字号，也不要复用带圆形背景的 `.board-label`。

### 4. 保留真实点击热区与可访问名称

- 视觉文字继续 `pointer-events:none`。
- `.board-hit` 的约 34px 点击范围保持不变。
- `aria-label` 应包含原谱显示文字或类型，例如“变化点 I9，标记 #”，方便读屏和测试。

### 5. 不夸大 raw 字段完成度

在没有原格式证据前，可以保留 conservative helper；但应把“boardText 映射”与“原始颜色/标记字段解析”分开描述。若后续找到 rawColor/rawMark，必须再扩展 compact index 和 IndexedDB round-trip。
