~~~text

beforeDraftOps = 当前草稿操作数

assert(stones === beforeStones + 1)

~~~

~~~text

depth === beforeDepth + 3
stones === beforeStones + 3
draftOps >= 3
~~~

如果测试目的是“新增三步”，就不能使用 >= 1 作为通过条件。
