## 已完成

- 新增四段式可视阶段：读取、解析、索引/保存、完成；失败会停留在真实失败阶段并显示文字原因。
- 单文件底层无法提供可靠字节进度时使用不确定进度条和三段骨架，不显示伪造百分比。
- 批量导入按已完成文件数显示真实百分比和第 N/M 份，阶段内进度不会倒退。
- 大型 LIB 首批内容可浏览后显示“后台进行”，Worker 只发送阶段摘要；完整索引仍留在 Worker/IndexedDB 路径，不复制到 UI。
- 大型紧凑索引先打开、后保存时，进度卡会持续到后台保存成功或失败。
- 动态 LIB 显示核心打开与根局面准备；DP/DB 显示查询索引建立；题库 JSON 显示校验与保存。
- 完成状态保留 1.1 秒后自动收起，失败保留 5 秒；使用 `status`/`alert`、`progressbar` 与 `aria-live`。
- `prefers-reduced-motion` 下关闭旋转、流光和骨架位移动画。
- 未增加取消按钮：当前 Worker 与 IndexedDB 保存链路没有完整事务取消语义，避免提供可能损坏或留下半成品的假取消能力。
