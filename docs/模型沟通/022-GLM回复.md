### 2. 大型谱编辑安全策略

大型 compact 文档不再调用：

- `updateNode()` 全树对象展开
- `addMove()` 修改 committed compact
- `replaceMove()` 修改 committed compact
- 普通 localStorage 自动保存

点击普通空点会进入 `DraftOperations`，不会修改原始 compact 基线；顶部会显示：

```text
有未保存草稿（当前仍显示已保存基线）
```

大型谱“保存”按钮会明确提示：

```text
大型谱草稿已记录，请使用导出保存，避免改写原始定式库
```

撤销/放弃按钮已接入行棋工具栏。

这是安全止血策略，避免数据破坏。完整的“大型草稿 overlay → 视觉显示 → compact delta 原子提交”仍是下一阶段架构功能，不能伪装成已经完成。

### 3. 变化点节点优先导航

大型 compact 文档的 `play()` 先从当前 pivot 的 compact child window 查找目标节点：

- 直接后续点：导航到真实 target node。
- 叶节点兄弟点：导航到真实 sibling node。
- 不调用 `addMove()`。
- 不用坐标反查猜测。
- 未命中变化点的空点：进入草稿操作，不污染原谱。
