# 070-GPT 回收站功能实现与验收

日期：2026-08-29

## 本轮目标

为棋谱库增加可恢复的回收站，满足项目稳定性基线中“删除可从回收站恢复”的要求，同时兼顾大型棋谱的 IndexedDB 分层存储和题库数据。

## 已完成

- 普通棋谱：删除时保存完整 `GameDocument`，移除正式库和草稿，并保留原文件夹。
- 大型棋谱：新增 IndexedDB 8 版本回收站 stores，删除时在数据库内部迁移文档、摘要、草稿和索引分块，不将大谱物化到 localStorage。
- 用户题集：支持删除、恢复和彻底删除；内置题库保持只读，不提供删除按钮。
- 界面：棋谱页和题库页都提供“回收站”入口；列表显示类型、来源、原文件夹和删除日期；支持恢复、彻底删除、清空。
- 备份：localStorage 回收站索引与 IndexedDB 回收站 stores 一并纳入现有备份/恢复协议；旧备份缺少这些可选字段时按空回收站兼容读取。

## 数据与边界

- 回收站索引：`banbu-recycle-bin-v1`。
- 大型棋谱数据库：`banbu-gomoku-large-library`，数据库版本从 7 升至 8。
- 删除变化分支仍然是当前棋谱草稿内的编辑操作，不进入资料回收站。
- 彻底删除不可恢复；清空回收站会永久删除其中的大型棋谱分块。

- `npx tsc --noEmit`：通过。
- `npm run build`：通过，产物约 4.86MB，低于 20MB 门禁。
