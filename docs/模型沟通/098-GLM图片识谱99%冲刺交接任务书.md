- 最后 5 个修复（全部有实证数据支撑，勿回退）：
  1. **外框厚度门槛**（scoreGridWindow 内 `outerThicknessShare`/`outerFrameShare` + consider 的 `outerFrame` 失败项）：±2 窗口内中位游程 ≥4px = 装饰边框 → 窗口锚定在边框上（差一行/列）→ 拒绝。修好 053/081/011 类"边框锚定窗"。注意：±4 窗会误伤小边距主题（010 教训），必须保持 ±2。
  2. **有效率门槛 0.72 → 0.6**（validRowCount/validColumnCount）：黑上黑等局部不可见棋子压低行有效率天花板。离线实证：image-2 假窗 @0.6 只有 2 行有效，真窗 13-15 行——分离度充分。
  3. **blob 双通道**（stoneBlobAt）：`distance ≥ 55 && markedShare ≥ 0.5 || (distance ≥ 25 && spread ≤ 30)`——notebook 红勾等笔画标记圆盘采样必然混色（spread 81），高置信距离单独放行；gold 线空交点靠 markedShare 挡住。
  4. **横幅区行拆分判据**（zone filter）：行 0 用 stub≥2；行 1 用"相对亮度（fg ≥ bg+20）+ dd<0.3"或"dd ≥ 0.3 保留"。dd=darkDiscShare（圆盘内比背景暗 40+ 的像素占比）、db=darkBelowShare（暗像素在下半占比）。这些值在运行间会漂移 ±0.05，阈值必须按实测留余量。
  5. **彩色标注饱和度 34 → 50**（jade 真玉子饱和度 38-40 曾被误吞）+ brightStone 逃生门（th ≥ 35 && disc ≥ 0.5，修 072-H7）+ hollowStone core<0.4（修 006/075-G7）+ blob 阈值 25（修软边材质）。
