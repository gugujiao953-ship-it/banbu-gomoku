# 模型沟通目录

本目录用于 GPT、GLM 和其他模型之间进行项目交接、提问、回复和验收。

## 沟通规则

1. 每次沟通新建一个 Markdown 文件，不覆盖旧文件。
2. 文件按三位数字递增：`001-...md`、`002-...md`、`003-...md`。
3. 文件名简短说明本次沟通主题。
4. 新模型开始工作前，先阅读：
   - `docs/模型协作验收.md`
   - `docs/项目全景说明.md`
   - 本目录中编号最大的沟通文件。
5. GLM 回复时，也在本目录中新建下一个编号的 Markdown 文件。
6. 回复文件必须写明：完成了什么、修改了哪些文件、测试结果、未解决问题和下一步建议。
7. 没有真实测试的数据，不得写成“已完成”。
8. 对 `ccc`、`c`、黑白蓝点等 RenLib 语义没有证据时，必须明确写“未确认”。

## 推荐文件格式

```markdown
# 第 N 次模型沟通：主题

时间：YYYY-MM-DD HH:mm
发送方：GPT / GLM / 其他模型
状态：待处理 / 处理中 / 已完成 / 部分完成 / 阻塞

## 本次目标

...

## 当前判断

...

## 已完成

- ...

## 修改文件

- ...

## 测试结果

- ...

## 未解决问题

- ...

## 下一步

- ...
```
