# 084｜分支树平移与长按快捷操作

日期：2026-08-30

## 本轮实现

- “棋谱树”入口与面板文案改为“分支树”。
- 分支树画布支持指针拖动平移，并默认支持双指缩放与重置；节点触摸长按约 620ms 显示环形进度反馈，完成后弹出复制、剪切、粘贴、删除分支快捷菜单。
- 剪切复用现有子树剪贴板与删除草稿命令；复制/粘贴/删除继续经过现有数据层能力与只读防线。
- 棋盘在双指缩放放大后支持单指平移滚动查看隐藏区域，移动过程中抑制误落子点击。
