# 081｜首次欢迎、会话恢复与最近项目

日期：2026-08-30  
任务：最近棋谱/棋题/导入、退出后恢复上次局面、首次欢迎弹窗

## 设计取舍

- 不新增“工作台”首页，也没有移除或隐藏主界面现有视觉内容。
- 最近棋题放在“棋谱库 → 题库”顶部，沿用题库已有入口；最近棋谱与最近导入分别复用棋谱库和现有导入 Sheet 的信息架构，避免首页重复堆叠。
- 最近棋题默认展示最多 4 项，按 `PuzzleProgress.updatedAt` 倒序，显示题集、尝试/完成状态和更新时间，点击后直接进入对应题目的做题模式。
- 最近导入继续使用 `src/recent-imports.ts` 和既有“最近导入列表”设置，不新增平行存储。
- 会话恢复只保存恢复所需的最小游标：棋谱 ID、节点 ID、模式，以及大型棋谱 ID 或题库/题目 ID。恢复到不存在的节点时回退到根节点；目标棋谱或题目不存在时回退到普通空白棋局或当前默认路径。
- 恢复开关默认开启，以兼容升级用户原有活动棋谱/草稿恢复习惯；关闭后冷启动创建新的空白棋局，不读取旧活动棋谱和旧草稿作为启动局面。
- 首次欢迎弹窗仅在全新安装显示。检测到旧版活动棋谱、棋谱库、默认棋谱、大型棋谱或题库进度等旧存储时，视为升级用户并直接写入已读标记，避免升级用户反复弹窗。
- “使用手册”按钮先记录已读，再打开已有手册 Sheet；设置/关于页原有手册入口保留。

## 兼容策略

- 存储键为 `banbu-restore-last-position-v1`、`banbu-last-session-v1` 和 `banbu-first-run-welcome-v1`，解析失败时采用安全默认值。
- 旧用户没有恢复开关时默认开启；已有旧活动棋谱/草稿的用户不因新增欢迎弹窗被打断。
- 普通棋谱仍沿用 `renju-note-active-v1`、`renju-note-library-v1` 和 `renju-note-draft-v2:*`；恢复状态只记录游标，不替换原活动棋谱和草稿机制。
- 大型棋谱只记录现有大型存储 ID，不把大型树复制到 localStorage；分页/动态数据库没有可稳定持久化的完整节点树，恢复失败时允许回退到已载入根节点或空白局面。
- 关闭恢复开关只影响冷启动读取，不清理用户已有棋谱、草稿、最近导入或题库进度。
- QA 页面通过 `?qa=1` 跳过首次欢迎遮罩，避免历史浏览器专项被新手弹窗阻塞；正常用户路径不受影响。
