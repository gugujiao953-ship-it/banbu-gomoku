- **引擎**：rapfi WASM 单线程。两档制——轻量随包（94KB）/ 强力 47.4MB 应用内下载（IndexedDB + 会话 blob）。**v3 包 = 官方原样 `.bin.lz4` 布局**（v1/v2 repack 致 NNUE 从未生效，勿再 repack）；`scripts/verify-rapfi-pack.mjs` 校验包字节/wasm SHA。YXBOARD 颜色 = SELF/OPPO 相对引擎 + 黑先世界（勿回退）。
- **分析线**：`startThink`（App.tsx）→ `AiWorkerController`（单活动互斥）→ 常驻 worker。持续分析=滚动续算（内部预算 5000ms，已无 UI 时长）；自对弈=每步时限滑杆 1–10s；提示/做题分析=有界预算（打谱 10s、做题 5s）+ 杀棋即落（`stopOnProvenWin`/`finishOnBareMove`）。
