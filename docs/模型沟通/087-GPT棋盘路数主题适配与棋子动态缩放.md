# 087｜棋盘路数主题适配与棋子动态缩放

日期：2026-08-30

## 本轮完成

- “打谱 → 更多 → 棋盘路数”、设置页和快捷中心的 5–21 路选择器统一增加 `board-size-select` 标识与无障碍名称，默认仍为 15 路。
- 路数控件改用 `--surface`、`--surface-border`、`--paper`、`--ink`、`--green` 等语义令牌，兼容深色、青花瓷、雨幕、像素、赛博及其他主题；原生下拉菜单的选项颜色也跟随主题。
- “更多”面板路数卡片取消会造成横向溢出的固定最小宽度，窄屏下压缩内边距和字号，大屏保留合理最大宽度；设置页和快捷中心选择器保留足够触控高度。
- 棋子绘制半径随网格间距动态计算：`stoneRadius = clamp(gap * 0.43, 10, 24)`，并同步缩放经典、玉石、云子、墨蓝、黑白、练习本、青花瓷、雪晶、终端及黑钻白金等棋子风格；手数、获胜环、最后一步、注释/书签标记和点击热区同步调整。
