## 已完成

### 1. 修复 Worker 结构化克隆风险

此前 `formats.ts` 已返回 lazy Proxy 文档，Worker 直接 `postMessage(result)` 不安全，可能导致代理结构化克隆异常或结果不完整。

现在 Worker 对有 compact index 的结果执行：

```text
取出 document.nodes
保留普通文档元数据
nodes 替换为空对象
发送 plain metadata + compactIndex
```

App 收到后再调用：

```ts
createLazyDocument(base, compactIndex)
```

这样 Worker 消息不包含 Proxy，也不包含完整节点树。

### 2. 增加 Worker 导入诊断

Worker 消息新增：

```ts
compactDiagnostic: {
  hasCompact: true,
  nodeCount,
  rootId,
  rootIndex,
  rootFirstChild
}
```

没有 compact 时明确发送：

```ts
{ hasCompact: false }
```

App 将其保存到：

```ts
window.__banbuImportDiagnostic
```

### 3. 修正黑盒等待竞态

黑盒脚本以前只等待：

```ts
.import-progress 消失
```

这可能早于 Worker 结果诊断状态写入。现在还等待：

```text
window.__banbuImportDiagnostic 出现
或 toast 出现
```

避免读取过早。
