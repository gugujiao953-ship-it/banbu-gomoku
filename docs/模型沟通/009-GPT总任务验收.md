## 四、compact 和文档绑定

Worker 端确认：

- plain metadata 不含 Proxy。
- compactIndex.nodeCount 大于 0。
- rootId、rootIndex 正确。
- firstChild、nextSibling、childCount 可读。
- 统计不依赖 Object.keys(document.nodes)。

App 端确认：

- 收到 Worker 后从 base + compactIndex 创建 lazy document。
- App 最终使用该 lazy document，而不是 Worker 返回的普通完整 document。
- duplicate 路径不能覆盖刚导入文档。
- saveCompactIndex 后 active document 保持 compact 关联。
- getCompactInfo(document) 能稳定返回 compact 信息。

- storageMode 为 compact-index。

## 七、标记语义必须实现

爱五子棋显示层约定：

- a：胜点、好点、推荐变化。
- c：败点、坏点。
- ccc：c 类败点，不应大量显示为普通 ccc 文本。
- 黑点：可行或推荐后续。
- 白点：败点或不推荐后续。
- 蓝点：特殊类别。

RenLib 原始字段的正式标准名称可以继续调查，但不能因此不实现显示层语义。数据结构必须保留 rawText、rawMark、rawColor/status、semantic 和 displayKind。
