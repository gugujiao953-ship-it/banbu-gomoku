## 已完成

### 1. 增加可序列化 compact 诊断

新增 `compactDiagnostics(document)`，始终返回明确字段：

```ts
{
  hasCompact: boolean,
  nodeCount: number | null,
  branchCount: number | null,
  firstBranchId: string | null,
  rootFirstChild: string | null,
  rootChildCount: number | null
}
```

不再依赖 `undefined`，避免通过 Playwright/JSON 后变成空对象 `{}`。

### 2. Worker 返回导入阶段诊断

`record-import.worker.ts` 现在额外返回：

```ts
compactDiagnostic: {
  nodeCount,
  rootId,
  rootIndex,
  rootFirstChild
}
```

App 在 Worker 消息到达后保存：

```ts
window.__banbuImportDiagnostic
```

这样可以对比：

- Worker 刚生成的 compact 状态。
- App 当前 document 的 compact 状态。

- IndexedDB 数据库
