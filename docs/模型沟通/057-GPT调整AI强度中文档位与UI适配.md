# 057-GPT：调整 AI 强度中文档位与 UI 适配

日期：2026-08-29

## 本次调整

AI 人机设置中的强度档位统一为：

1. 初级：600ms / 深度 32
2. 中级：1200ms / 深度 48
3. 高级：1800ms / 深度 64
4. 大师：3000ms / 深度 80
5. 不限：最长 5 分钟保护 / 深度 128
6. 自由：用户自定义思考时间和搜索深度

默认档位为“高级”，与完整三手胜4-高级题复测的 Rapfi 19/30 基准一致。

## UI 行为

- AI 设置面板新增六档三列响应式选择卡；
- 小屏自动切换为两列，避免文字挤压；
- 选中状态使用现有绿色强调样式；
- 选择“自由”后显示思考时间和搜索深度两个滑杆；
- 选择“不限”仍有 5 分钟浏览器保护上限，避免页面无限等待；
- 人机棋谱事件中记录当前 AI 档位，方便复盘时确认使用的强度；
- 当前棋局保存创建时的 AI 档位，不因之后修改设置而改变本局标记。

## 2026-08-29 追加调整

- “自由”的思考时间上限从 10 秒提高到 300 秒（5 分钟）；
- “不限”的保护上限同步提高到 300 秒，避免自由档反而弱于不限档；
- 自由档新增可直接输入的秒数输入框，范围为 0.3–300 秒；
- 输入框与时间滑杆双向同步，仍保留滑杆进行快速调整；
- 输入超出范围时自动限制到 0.3–300 秒。
