# 089｜外观与音效子目录及棋盘透明度

日期：2026-08-31

## 本轮目标

承接 088 轮设置页重构，解决“外观中心”打开后内容过长的问题，并增加棋盘透明度，让页面背景主题可以透过棋面显示。

## 已完成

- 设置主分类由“外观中心”改为“外观与音效”。
- 外观与音效内部拆为四个默认收起的子目录：
  - 主题：应用主题和自定义背景。
  - 棋盘：棋盘材质、棋盘透明度和默认棋盘路数。
  - 棋子：棋子材质和棋子透明度。
  - 声音与音效：音效开关、音色、音量、试听和界面动效。
- 设置搜索支持“棋盘透明度”“棋子透明度”“背景透出”等关键词；搜索命中时自动展开对应子目录。
- 新增 `src/board-opacity.ts`，使用 `banbu-board-opacity-v1` 本机持久化，范围 35%–100%，默认 100%。
- 棋盘透明度只作用于 SVG 的棋面底色/边框；网格、坐标、棋子、编号、禁手、胜线、候选点和交互热区保持独立，避免透明后不可读或不可操作。
- 棋盘承载层改为透明，使低透明度棋面透出应用主题，而不是透出固定木色。
- 棋盘透明度已纳入应用备份与恢复；无该字段的旧备份按 100% 兼容。
- 使用手册补充子目录结构、棋盘透明度语义和操作步骤。
