# 085｜默认棋盘大小与响应式快捷中心

日期：2026-08-30

## 本轮实现

- 新增持久化“默认棋盘大小”，可选 5–21 路，初始默认 15 路；新建空白棋谱使用该设置。
- 设置页“棋盘与棋子”中增加默认棋盘大小折叠子目录。
- 左上角快捷中心增加默认棋盘大小选择；自动演示、思考助手和外观选择均改为可折叠子目录。
- 打谱“更多”增加棋盘路数选择。切换会创建对应路数的新空白棋谱；已有草稿继续使用原草稿保护流程，避免裁剪现有棋局。
- 快捷中心在大屏默认占视口左半边，最大宽度 520px；手机端使用不超过 88vw 的自适应宽度。
