# 073-GPT 批量编辑与无障碍字号实现验收

日期：2026-08-29

## 实现范围

### 批量编辑（P2-8）

- 棋谱库普通棋谱支持进入批量模式。
- 支持逐项选择、全选当前搜索结果、清空选择。
- 支持批量替换节点注释与局面文字。
- 支持批量导出 SGF；单次最多导出 20 份，避免低内存设备产生过大瞬时缓冲。
- 大型 LIB、DP、DB 不参与批量改写，保留原始数据库边界。

### 无障碍与字号（P2-10）

- 新增正常、大字、特大字三档字号偏好，分别为 100%、115%、130%。
- 设置通过 localStorage 持久化，刷新后保留。
- 字号不对棋盘 SVG 做整体缩放，降低移动端布局错位风险。
- 增加跳到主要内容、主要内容锚点、导航当前页语义和批量状态播报。

### i18n（P2-11）

- 本轮按用户要求撤回英文入口和语言切换，不在当前版本保留半成品英文 UI。
- i18n 框架后续单独规划，避免只翻译少量公共按钮造成中英文混排。

## 验证结果

- `npm test -- --run`：以本轮最终代码重新执行，结果见当前项目状态文档。
- `npm run build`：通过，dist 约 4.88MB，低于 20MB 门禁。
- `git diff --check`：通过，仅有工作区既有的 CRLF 提示。
- Playwright 390×844：验证字号档位切换、折叠设置分组、棋谱库批量入口、批量模式工具条和选择状态。

## 已知边界

- 批量操作暂不支持题库批量编辑和大型数据库批量写回。
- 英文 i18n 暂缓，当前不应宣称已完成国际化。
- 批量导出直接生成多个 SGF 下载，不打包 ZIP，以保持依赖和内存开销较小。
