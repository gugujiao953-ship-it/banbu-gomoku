# 099｜GLM 全主题文字对比度审计与修复

日期：2026-09-03
对应诉求：用户报告部分主题下文字看不清——「无障碍与字号」未选中的两个选项几乎不可读，「自动演示」同样，要求排查所有类似情况并优化。

## 方法（工具保留在 experiments/contrast-audit-2026-09-03/）

1. **静态 token 审计**（`audit.mjs`）：解析 styles.css / design-tokens.css / library.css 的全部 20 个主题作用域（含合并选择器、8 位带透明度 hex、color-mix），对关键配色组合（ink/paper、ink/surface、muted/paper、button-muted/surface-2、green-2/jade 等）计算 WCAG 对比度，并自动建议达标替换值。
2. **运行时扫描**（`sweep.mjs`，Playwright）：真实渲染 + 打开设置页展开全部分组，在 20 个主题下遍历可见按钮/下拉框/文字元素，向上回溯有效背景色，报告 <4.5:1 的命中（排除装饰性色板、材质预览）。

## 根因与修复

| 问题 | 根因 | 修复 |
|---|---|---|
| 暗色主题下「无障碍与字号」未选中选项不可读（1.04-1.21:1，9 个主题） | `.font-scale-options button` 硬编码 `background:#fff`，未接入语义色契约 | 改 `var(--surface,var(--paper))` + `--surface-border`，小字用 `--button-muted-text` |
| 暗色主题下「自动演示」等下拉框不可读（约 1.1:1） | `library.css` 的 `.setting-choice-row select` 用了**不存在的** `--surface-1`，永远回退 `#fff`，且 library.css 在 styles.css 之后加载压过契约 | 改 `var(--surface, var(--paper))` |
| 9 个主题说明小字 <4.5:1（最低 rice 3.44） | 各主题 `--muted` 偏浅 | 按审计建议逐主题加深至 ≥5.2:1（root/mono/bamboo/snow/eye/plum/rice/pale/kawaii/baroque，design-tokens 根 muted 同步） |
| 大批硬编码暖灰小字（#938c82/#918a80/#928b80/#827b72/#8b857a/#aaa298 等 16 处规则） | 旧版假定浅色底 | 全部替换为 `var(--muted)`；`settings-feature-note`（玉石底）用 `--button-muted-text` |
| kawaii/baroque 选中态标签 3.6-4.4:1 | `--green` 直接管 `--jade` 底 | 契约新增：全部 `button.selected`、`.rule-pill`、`.branch-list em`、`.support-row`、`.dock-tabs button.active`、`.bottom-nav button.active`、`.settings-command-copy>span` 统一 `var(--green-2)`（全部主题 ≥6.2:1） |
| 暗色主题「选择」按钮（存储授权）不可读 | `.storage-action` 硬编码浅绿底，暗色覆盖只写了 `dark` 一个主题 | 底色改语义 surface + `--green-2` 文字，删除单主题覆盖 |
| `.sound-profile` 描述文字硬编码 #938c82 | 同上 | 改 `--button-muted-text` |

## 验收

- 静态审计：20 主题全部关键配色组合 ≥4.5:1（0 失败）。
- 运行时扫描：20 主题真实渲染文字命中 0（保留例外：主题色板/材质预览等装饰图形，以及透明度预览中叠在木纹贴图上的装饰性手数"12"）。
- 截图核验 dark/snow/kawaii 三主题「无障碍与字号」「自动演示」「声音与音效」均可读。
- Vitest 317/317；`npm run build` 通过，dist 8.05MB（上限 20MB）。

## 后续注意

- 新增控件一律用语义 token（`--surface`/`--button-muted-text`/`--green-2`），不要硬编码颜色；新增主题后跑一次 `audit.mjs` + `sweep.mjs`（`node sweep.mjs` 需 dev server 运行中）。
- `--surface-1` 是历史笔误变量名，主题里只有 `--surface`/`--surface-2`/`--surface-3`，勿再引用。
