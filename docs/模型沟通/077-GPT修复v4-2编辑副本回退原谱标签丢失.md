# 077-GPT 修复 v4-2 编辑副本回退原谱标签丢失

时间：2026-08-30  
发送方：GPT  
状态：已完成并通过真实文件回归

## 本次目标

修复真实文件 `D:\五子棋\其他\九天指南v4-2.db` 的以下流程：

`H8 → G9 → J6 → G10（分支终点）→ 在此处继续编辑 → 上一手回退`

回退后，来路分支点原本的原谱文字必须保留，不能被无文字灰点覆盖；同时不能破坏分支点击和继续续谱。

## 根因

DP/DB 查询返回的标签属于父局面 `query.branches` 中的“边标签”。选中分支后，动态路径节点只保存了坐标和局面查询结果，没有把这条边的标签带到路径节点。进入编辑副本时复制的是这个动态投影，因此回退时原标签已经丢失，界面将节点误判为普通变化点并绘制灰点。

## 已完成

- `src/dp-view-session.ts`
  - 对每个已选路径节点，从父层 `branches` 按坐标找回对应分支。
  - 将原谱标签写入路径节点的 `boardText`、`renLibNativeLabel` 和 `renLibLabelColor`。
  - 编辑副本复制动态投影后，回退仍能保留原谱标签。
- `qa/dp-a-repro.mjs`
  - 增加真实流程回归：编辑副本连续回退检查 `G10=A`、`J6=彗`、`G9=斜`。
  - 同时断言这些位置没有错误的 `.renlib-variation-dot` 灰点。
  - 回到终点后继续点击旧分支位置，确认仍能创建新的本地落子。
  - 使用实际按钮无障碍名称 `到最后一手` 返回终点。
