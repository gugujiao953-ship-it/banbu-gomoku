## 当前进度

最新一轮已经完成并通过验证的功能：

- 只有同一节点存在两个或以上后续着法时，才判定为分支。
- “变化”已改为“分支”相关交互。
- 支持回到上一个分支点。
- 支持按棋谱分别保存分支书签；书签可跳转、重命名、删除。
- 有书签的局面，在最新一步棋子的左上角显示分支书签图标。
- 开发预览增加了 Service Worker 重置入口，便于清除旧版缓存。
- 分支面板已将“回到上一个分支点”作为创建新分支入口；书签默认展开，保存和行内重命名可直接操作。
- “改着”和“评价”编辑入口已移除；导出移到右上角导入按钮旁，查找移入“更多”。
- 查找已覆盖普通棋谱与紧凑大型棋谱中的棋盘标注（文字、坐标和形状）。
- 全站导入统一使用向下箭头，导出统一使用向上箭头；标注入口移到棋盘工具栏，黑白落子与锁定控件靠右对齐。
- 底栏新增 AI 入口，可创建本地人机棋局并选择连珠/标准规则、是否启用黑方禁手，以及执黑先手或执白后手。
- 标注面板已调整回横向按钮布局：显示样式与颜色保持横向排列，数字、局面结论和字母按钮按一到两行紧凑排列；自定义文字独占最底部整行，常见手机高度无需滚动即可看到全部操作。
- 标注文字默认采用导入棋谱相同的中文字体与墨黑色；颜色扩展为 12 种，并保留圆圈、三角、叉号的独立样式选择。
- Rapfi 已固定使用随包本地 WASM / 数据，不再请求 `gomocalc.com`；棋局不会上传到第三方。
- 标注面板已增加“删除现有标注”红色按钮，放在自定义文字输入框下方；形状标记说明已移到棋盘标注总说明。
- 导出页已重做为“选择格式导出 / 直接导出”两级结构，并记录导入文件的原始格式。SGF 与 JSON 支持完整重编码；已打开的 LIB、DP、DB 支持原文件直接导出，但不伪造二进制转换文件。
- 设置页的导出入口和格式兼容说明已同步更新。
- 题库导入说明已改为真实格式描述：二维 JSON 数组，每题由“坐标,颜色编号”字符串组成；“关于”页已改为个人 Vibecoding 项目、侵权处理、后续维护和 GitHub 下载说明。

## 关于 Codex 会话异常

目前观察到的是 Codex 任务历史投影异常，不是本项目代码导致：

- 多个新旧任务在分叉时出现 `thread-store internal error`，典型信息是 `expected ordinal ..., got ...`。
- `111` 新对话即使建立后也会复现，说明不是单纯因为旧聊天太长，也不是只绑定项目即可解决。
- 重新打开后只看到最初交接消息，说明后续上下文没有被当前任务历史投影完整恢复。

本文件是项目级的抗丢上下文方案：即使聊天重启、重开或无法分叉，也能从当前工作区恢复。它不能修复 Codex 服务端的历史投影或分叉接口；接口问题需要平台侧修复。在平台修复前，使用“新对话 + 本文件”可以保持轻量，不需要回到旧大对话。
