# 074-GPT 设置反馈入口与邮件 / GitHub 发送

日期：2026-08-29

## 实现范围

- 设置页新增“反馈与建议”入口。
- 反馈类型分为：遇到问题、功能建议、其他反馈。
- 表单支持 1200 字内容、可选回复邮箱和最少 5 字校验。
- GitHub 路径打开仓库的预填 New Issue 页面，自动带入反馈类型、内容、版本、页面和浏览器信息。
- 邮件路径使用 `mailto:` 调用系统默认邮件应用；收件地址由构建变量 `VITE_FEEDBACK_EMAIL` 配置，不把私人邮箱硬编码进仓库。
- 另外提供复制反馈文字，作为邮件客户端不存在或 GitHub 暂时不可用时的降级路径。

## 隐私与边界

- 用户点击发送前不上传任何内容。
- 默认不附带棋谱、导入文件、本地存储数据或诊断日志。
- 自动附带的环境信息只有版本、当前页面和浏览器设备信息。
- 回复邮箱仅保存在本机，便于下次填写；不会自动发送给第三方。
- GitHub Issue 最终提交由用户确认，邮件最终发送也由用户确认。

## 邮箱配置

复制 `.env.example` 为本地环境配置，并设置：

```text
VITE_FEEDBACK_EMAIL=你的公开反馈邮箱
```

该地址会进入 Web/APK 构建产物，因此应使用公开联系邮箱，而不是需要保密的账号地址。未配置时，邮件按钮会保持禁用并明确提示，GitHub Issue 仍可使用。
