# 086｜做题界面、禁手选项与青花瓷主题优化

日期：2026-08-30

## 任务边界与兼容判断

- 本轮只从“做题”上下文移除“查找 / 跨谱查找”，没有删除搜索组件、索引或全局能力。普通棋谱/研究工作流仍从“更多”进入查找与跨谱查找。
- 工作区存在多项并行开发，本轮没有 reset、回退、清理或覆盖其他任务；复用了共享 `BottomSheet`、主题语义 token、`RuleSet` 与 `forbiddenReason()`。
- 旧题集没有规则字段时，默认保持历史语义：**无禁手**。这样升级后不会突然阻止原本可落的黑棋，也不会改变旧题答案。

## 做题规则信息架构

### 用户只看到两个选项

- `禁手`：使用项目统一连珠判定，只限制黑方；三三、四四、长连会阻止落子并说明原因。
- `无禁手`：双方自由落子，不显示做题禁手点、不阻止禁手形状；长连沿用旧题集的自由五子棋胜负语义。
- 移动端采用紧凑分段单选，位于做题状态区，不占用棋盘几何空间。

### 规则优先级

规则解析顺序固定为：

1. 题目 `Puzzle.rule`
2. 题集 `PuzzleCollection.rule`
3. 用户做题偏好 `banbu-puzzle-rule-preference-v1`

题目或题集显式携带规则时，控件显示“题目规则”来源并锁定，避免 UI 显示一套、判题静默使用另一套。导入只接受明确文本或布尔规则元数据；第三方数字规则码含义不统一，因此不猜测。

### 生效链路

- 用户落子：`puzzleMoveLegality()` 在禁手模式下对黑方调用 `forbiddenReason()`；白方始终不受黑方禁手限制。
- 胜负与判题：题目会话把最终 `RuleSet` 写入 `document.metadata.rule`，`winnerAt()` 按该规则判断恰好五连或自由长连。
- 禁手标记与解释：仅在做题禁手模式、轮到黑方且允许显示辅助时计算 `forbiddenPoints()`；无禁手模式不残留标记或禁手 Toast。
- 陪练、演示与后续变化：AI worker、Rapfi fallback、VCF 校验和陪练合法性兜底统一读取题目会话规则；如果引擎返回禁手点，会选择当前规则下的合法落点。
- 规则切换：若已经落子、正在思考或已有结果，会取消当前计算并重新创建本题会话，提示“当前作答已安全重置”，不保留半失效局面。
- 持久化：偏好写入 localStorage，并纳入完整备份的采集、校验和恢复。

## 题目与题集选择器

- 新增 `PuzzleSelectorSheet`：手机为 Bottom Sheet，桌面/平板为右侧抽屉；不再参与 `record-page` 正常文档布局。
- 首屏显示当前题集、当前题目、进行中/已完成状态；支持题集切换、题号/标题/题面搜索、长列表内部滚动、直接选题和继续下一题。
- 复用共享 `BottomSheet` 的 Escape、焦点圈定与焦点恢复，并开启 history 管理以支持浏览器/Android 返回键关闭。
- 打开做题选择器前会关闭普通 Sheet；打开普通 Sheet 或切换模式时也会关闭做题选择器，避免多层遮罩。
- 关闭选择器不重置当前题目或进度。共享 Sheet 锁定页面滚动时按实际滚动条宽度补偿 `body`，避免桌面/平板出现横向跳动。
- 动效仅为增强；`prefers-reduced-motion` 与应用关闭动效时直接显示最终状态，不依赖 `transitionend`/`animationend`。

## 青花瓷主题规格

统一 token 定义在 `src/design-tokens.css`：

- 瓷白 `--porcelain-white: #f8f5ed`
- 釉色 `--porcelain-glaze: #edf2f2`
- 浅蓝纹样 `--porcelain-pattern: #b8d1dd`
- 钴蓝结构 `--porcelain-cobalt: #1d5688`
- 靛青强调 `--porcelain-indigo: #123f73`
- 藏青正文 `--porcelain-navy: #102b4a`

主题、棋盘和棋子预览卡同步更新；棋盘网格、星位、坐标、落子标记和禁手提示使用分层深蓝/红色，不让壁纸纹样干扰棋子识别。青花瓷当前定义为浅色主题，即使系统处于深色环境也安全保持 `color-scheme: light`，避免浏览器原生控件出现不可读的深色混搭。

对比度契约测试覆盖：藏青/瓷白、白字/钴蓝、靛青/浅蓝背景均达到 WCAG AA 4.5:1。
