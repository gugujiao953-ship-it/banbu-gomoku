# 092｜读谱紧凑布局与本机标注

日期：2026-08-31

目标副本：`D:\Projects\五子棋2`（源码基线来自 `D:\Projects\五子棋\项目资料\半步五子棋打谱`；本轮未修改原项目工作树）

## 本轮实现

- 移动端首屏布局在 `src/library.css` 末尾增加 600px 及 370px 以下覆盖：压缩 `record-page`、`workspace-status`、`context-dock`、dock tabs 和 dock panel 的外框间距、上下留白与间隙；常用按钮仍保留约 40–46px 的触控高度，目标是让 360/390/412px 宽度首次打开时尽量同时看到棋盘和常用操作。
- 读谱入口继续复用 `RecordSelectorSheet`：普通棋谱、大型棋谱、文件夹、资料归类和选择列表与打谱共用；在读谱状态下从选择器打开新棋谱会保持 `review` 模式。顶部状态、棋盘、起点/前后手/终点、自动演示和分支树使用同一套导航。
- 读谱渲染优先使用已保存的源棋谱。打谱中未保存的草稿在切换到读谱时不会泄漏到浏览画面，返回打谱后仍可恢复原草稿。
- 读谱期间跳过普通棋谱/活动快照自动写回；大型棋谱的异步草稿读取仅在仍处于同一份打谱文档时生效，避免快速切谱串入旧草稿。
- 棋谱选择器会把当前大型棋谱按大型数据库条目展示一次，保留文件夹归属、准确总数和当前项信息。
- 新增本机标注存储 `banbu-review-marks-v1`，以 `document.id + currentId` 隔离当前棋谱和局面。读谱可通过标注面板选择数字、文字、形状和颜色后点棋盘放置，也可长按/右键切换圆圈、三角、叉号；清除入口只删除本机标注。标注以浏览层叠加显示，不写回原棋谱节点、注释或元数据。

## 行为边界

- 读谱只能点击当前节点已有的直接变化或使用导航浏览；点击空位不会创建落子、分支、草稿或脏状态，叶子节点只提示已到棋谱末尾。
- `recordDraft`、棋谱元数据更新和分支树编辑命令在读谱下被拦截。分支树仍可定位、展开和浏览，但新分支、复制/剪切/粘贴、删除、重命名及书签编辑入口隐藏或不可用。
- 读谱标注是独立的本机状态，不等同于编辑棋谱；切换节点或棋谱时按键隔离，删除本机标注不会影响原谱已有标注。返回打谱后，普通打谱标注仍按原有草稿规则处理。
