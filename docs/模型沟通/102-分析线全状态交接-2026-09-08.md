## 一、30 秒架构

```
设置开关(enhancementSettings) ──> App.tsx startThink(options)
   startThink ──> AiWorkerController(单活动互斥) ──> 常驻 worker(public/rapfi/rapfi-worker.js)
       worker 握手: START / INFO RULE / [MAX_MEMORY] / TIMEOUT_TURN / MAX_DEPTH / SHOW_DETAIL 2 / YXBOARD / YXNBEST
       引擎: variant full = ./full/rapfi-single.js + wasm + rapfi.data(经 locateFile→dataUrl 覆盖)
             variant fallback = ./fallback/…(随包 94KB 网络)
       stdout → parseOutput: INFO(DEPTH/NODES/EVAL/WINRATE/BESTLINE) → progress(100ms 节流)
                              MESSAGE Bestline+裸坐标 → 终局宣告 → finish(有界轮 acceptBareFinal / 手动 finishOnBareMove / 杀棋 stopOnProvenWin)
       → App accept → setAiAnalysis(面板) 或 playMove=hint|selfplay → play()(正常落子通路)
```

- **winRate 永远是行棋方视角**（引擎侧），UI 在分析主统计里换算成「黑方胜率」（`blackWinRate(state, raw)`，state.mover 记行棋方）；**候选点数字/色调=行棋方视角**（谁的回合谁的好恶）。
- 引擎每手在**根节点搜全部合法着法**；`topN`(=选点数量设置) 只限制输出 PV 条数与展示，不是搜索范围。

## 三、引擎与包的关键事实（勿花钱重学）

1. **包格式只吃官方原样**：容器内权重是 `.bin.lz4`（文件名以 .lz4 结尾、config.toml 引用同名），**引擎 C++ 自己解压**。任何"预解压成 raw .bin"的 repack 会让评估器静默禁用（v1/v2 都栽过，桌面引擎隔离对照实验定案）。本地包=官方 `rapfi.data` 字节（SHA256 `2fa58b1c…b9d846d`，40,306,406B，在 `artifacts/nnue/rapfi.data` 与 `engine-packs/rapfi-full-v3.data`）。
2. **验证包/加载**：`node scripts/verify-rapfi-pack.mjs`（包字节=官方 && loader manifest 是 .bin.lz4 布局 && wasm SHA `20bb495a…36a5820` 同官方）。判"评估器在工作"看 `weight loaded in Xms` 日志，不是深度节点数（坏包=古典评估器也能到 depth15/百万节点）。
3. **START 不清 TT**（`start→restart→clear(false)`，searcher.h：`clearAllMemory` 才清）；规则/candidate-range/SEARCH_TYPE 变更才 `clear(true)`。→ 滚动续算与换手的置换表继承是真的：同面 4 轮实测 depth 13→17、每轮节点数千（TT 命中）。
4. **单线程是 Web 硬顶**（loader 无 SharedArrayBuffer/pthread；比赛=16线程×分钟级）。追平智子"秒开 99%"唯一正路=离线开局库（P1），不是调参。
5. 引擎会**超预算收尾**当前迭代再交终局（TIMEOUT_TURN 到点→完成进行中迭代→MESSAGE Bestline+裸坐标），worker 侧 deadline+grace 强停会丢这轮——`acceptBareFinal` 修的就是这个。
6. `INFO` 可调白名单：TIMEOUT_TURN/TIMEOUT_MATCH/MAX_MEMORY(RULE/MAX_DEPTH/MAX_NODE/SHOW_DETAIL/CAUTION_FACTOR/THREAD_NUM/SEARCH_TYPE…（源码 `Rapfi/command/gomocup.cpp` getOption()）。timectl 参数（advanced_stop_ratio=0.75 等）**不可运行时改**——实测不空转，别白折腾。
