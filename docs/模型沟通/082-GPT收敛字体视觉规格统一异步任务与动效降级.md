# 082｜收敛字体视觉规格、统一异步任务状态与动效降级

日期：2026-08-30  
任务：在共享工作区保留并行改动的前提下，补齐视觉规格、异步任务状态和无动画基线。

## 实施判断

现有项目已经通过 `vite.config.ts` 的 `scalable-ui-fonts` 插件，把 `src/styles.css` 与 `src/library.css` 中的像素字号转换为 `calc(... * var(--ui-font-scale))`；设置页的 normal / large / xlarge 选择因此会传播到主界面、棋谱树、Sheet、手册、导入和 AI 文案。无需再用会导致窄屏溢出的全局 `zoom`。

本轮采用兼容层：新增少量语义 token，不重写现有 CSS；新增 UI 无关的任务状态机，先接入 AI 思考和棋谱导入，保留原有 Worker、进度卡片和文案；动效通过根节点开关与系统 reduced-motion 统一降级，最终状态不依赖动画事件。

## 修改文件

- `src/design-tokens.css`
  - 新增字体族、display/title/body/label/caption/mono 文本层级、字重/行高、间距、圆角、触控目标、图标尺寸、背景/表面/文字/边框/强调/成功/警告/错误、阴影和 safe-area token。
  - 以 `--ink`、`--paper`、`--line` 等兼容别名接入现有品牌样式。
  - `data-motion="off"` 与 `prefers-reduced-motion: reduce` 统一将 transition/animation 置零，并保留静态 spinner/进度轨道可见。
  - 增加 360/390px 窄屏换行、Sheet 标题截断、控件间距收敛和横屏触控目标降级规则。
- `src/main.tsx`
  - 引入共享 token CSS。
- `src/features/tasks/task-state.ts`
  - 独立于 UI 的 `TaskManager`：`idle / queued / running / success / error / cancelled`；包含 taskId、kind、title、stage、progress、message、时间戳、result/error、retryable/cancellable。
  - 支持 AbortController、超时、取消、重试、进度边界、陈旧结果保护和应用重启后的中断恢复语义。
- `src/features/tasks/task-state.test.ts`
  - 覆盖状态迁移、已知进度钳制、取消后的旧结果丢弃、失败重试、超时和重启中断。
- `src/App.tsx`
  - AI 思考与导入进度通过任务管理器同步状态；原有 `thinkVisualState`、`ImportProgressCard` 和 Worker 代际校验保留，避免并行任务接口冲突。

## 异步状态迁移边界

- 导入：`beginImportProgress` 创建 `import-*` 任务，阶段更新同步到 task manager；完成/失败分别进入 success/error，现有短暂提示卡仍由原逻辑控制。
- AI：每次新一代思考创建 `ai-*` 任务；停止时 cancel，成功/异常时 success/error。原有 `thinkGeneration` 和 Worker terminate 继续作为底层竞态保护。
- 更新检查、VCF、备份/恢复、同步和数据库导航目前仍保留专属状态；后续接入只需调用同一 `TaskManager`，不要求伪造百分比。
- 任务状态没有写入持久化存储；若需要跨重启展示，必须先恢复为“应用中断/待重试”，不能显示运行中。

## 动效降级原则

- 关闭应用内动效或系统开启 reduced-motion 时，导航、Sheet、导入、AI、主题和棋谱树不等待 `transitionend`/`animationend`。
- 现有装饰动画仍可播放，但 `data-motion="off"` 会立即停用；静态首帧、边框和不确定进度轨道继续可见。
- 未使用 user-agent 猜测；能力差异由 CSS 媒体查询和根节点状态处理。
