## 已完成

### 1. 新增 compact 分叉诊断接口

新增：

```ts
compactFirstBranchNodeId(document)
```

该接口优先从 compact index 定位第一个真实分叉节点。

随后修正了旧索引兼容问题：不能只依赖 `index.childCount`，因为部分旧索引/恢复路径的 `childCount` 可能为 0。现在诊断接口直接沿：

```text
firstChild -> nextSibling
```

检查前两个有效孩子，并用循环保护避免损坏索引死循环。

### 2. 开发环境诊断入口

开发环境下挂载：

```ts
window.__banbuFindBranch()
```

调用后会把当前节点跳转到第一个真实分叉点，并返回节点 ID。

该入口只在 `import.meta.env.DEV` 下存在，不进入生产功能界面。

### 3. 黑盒脚本增强

`qa/large-lib-blackbox.mjs` 尝试调用开发诊断入口后再打开分支面板，并记录：

- 面板文案
- 真实行按钮数量
- 滚动后行数量
- 首行文本
- 是否点击真实分支行
- 刷新恢复

需要进一步确认以下事实：

1. `createLazyDocument()` 是否把 `lazyDocumentInfo` 正确绑定到当前 App 使用的 `document.nodes`。
2. `compactIndex` 是否真的包含 `childCount`，以及 `firstChild/nextSibling` 是否在加载和保存后保持正确。
