## 交互设计

### 统一顶部状态区

- 用 `UnifiedStatusBar` 替换棋盘页原先分散的工作区信息。
- 第一层只保留当前棋谱/棋题标题、来源或对局摘要；第二层显示当前位置、轮到哪方和当前状态。
- 状态按已保存、未保存草稿、自动演示、AI/VCF 分析、做题结果等语义切换，不重复顶部导航。
- 打谱、读谱、做题模式切换并入同一区域；AI 对弈时保留退出入口。
- 360/390/412px 下使用紧凑三列模式按钮和截断文本，不挤压棋盘；横屏、深色和减少动效均有对应样式。
- 保留隐藏的 `.workspace-current` 兼容文本，避免既有自动化和辅助读取路径突然失效。

### 棋谱树与分支操作

- 棋谱树继续使用底部 Sheet，首次进入、切换棋谱和打开局面时默认收起，不因当前节点变化自动弹开。
- 分支定位、新建、重命名、删除、展开后续、书签、复制和粘贴全部放到选中节点的就近操作区。
- 删除分支继续经过确认；高频定位、新建、复制、书签使用直接按钮，触控目标不小于 44px。
- 原独立分支入口不再承担主要操作；兼容 Sheet 只提示用户转到棋谱树。
- 大型紧凑棋谱仍按当前路径窗口读取；定位和浏览可用，完整子树复制/粘贴要求先创建可编辑副本，避免把未加载窗口误当完整数据。

### 复制与粘贴

- 点选节点后“复制分支”会复制该节点及全部后代，并在 Sheet 内显示持续可见的复制状态、节点数量、目标选择说明和取消按钮。
- 点选合法目标后使用“粘贴到这里”，不依赖右键菜单，适合触屏。
- 粘贴不会覆盖原分支；所有节点生成新 ID，父子关系、主变化指针、注释、局面文字、评估、标注、设置局面、RenLib 兼容注释和子树内书签均随新 ID 重映射。
- 粘贴作为一条 `add-subtree` 草稿操作记录，一次撤销即可整体回退。

## 数据模型与校验

### 子树剪贴板

`SubtreeClipboard` 当前版本为 1，包含：

- `sourceDocumentId`
- `rootId`
- `nodes`
- 子树范围内的 `bookmarks`
- `copiedAt`

粘贴前执行完整遍历和局面重放，拒绝以下情况：

- 源或目标节点缺失；
- 循环引用或断裂子树；
- 越界坐标；
- 目标局面已有棋子占用；
- 目标下已有相同直接着法；
- 子树内部重复着法；
- 行棋方与目标轮次不一致；
- 设置局面黑白重叠或坐标非法；
- 连珠规则下黑棋禁手。

失败时返回稳定错误码和中文原因，不修改原文档。成功时先完成全部校验，再一次性生成新节点和 ID 映射，避免半粘贴状态。

### 原子草稿

`DraftOperation` 新增：

```ts
{ type: "add-subtree"; parentId: string; rootId: string; nodes: Record<string, RecordNode> }
```

草稿投影、保存、撤销、恢复游标、大型棋谱派生版本节点计数均已识别该操作。原树和复制树不共享节点对象或 ID。

### 自由书签与迁移

存储键继续使用 `renju-note-branch-bookmarks-v1`，不新增预置标签或强制分类。新结构包含：

- `title`
- `note`
- 可选轻量颜色 `accent`
- `createdAt` / `updatedAt`

旧 `{ id, name, nodeId, createdAt }` 会把 `name` 迁移为可编辑 `title`，缺失字段使用安全默认值。读取时逐项迁移；保存前若发现旧存储 JSON 损坏，会先写入带时间戳的 recovery 副本，再保存新数据，避免静默丢失原字符串。

书签支持树内快速添加/取消、标题和备注编辑、轻量颜色、集中搜索以及一键跳转并关闭 Sheet。
