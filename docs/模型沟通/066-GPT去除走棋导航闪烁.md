# 066｜去除走棋导航闪烁

日期：2026-08-29

## 修改

- 移除棋盘导航时的整盘闪屏层。
- 移除上一手、下一手、起点、终点、分支跳转时的最后一步放大聚焦动画。
- 导航动作会主动清除残留的落子动画状态，避免“刚落子后立即上一手/下一手”把落子动画带到导航结果上。
- 正常新落子动画、非法落点反馈、胜线和结果提示保持不变。

## 验收

- `npm run build` 通过，dist 4.85MB，低于 20MB 门禁。
- Playwright 390×844 实测：完成一次落子后点击“上一手”，棋盘闪屏节点 0、导航聚焦节点 0、残留落子动画节点 0。
- `git diff --check` 无新增错误，仅保留既有 CRLF 转换提示。
