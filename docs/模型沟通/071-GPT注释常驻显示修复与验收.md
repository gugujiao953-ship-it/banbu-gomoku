# 071-GPT 注释常驻显示修复与验收

日期：2026-08-29

## 需求

注释功能点击一次后常驻显示，上一手、下一手和分支导航不自动影响显示状态；再次点击注释按钮关闭。

## 实现

- 移除 `currentId` 变化时的 `setCommentExpanded(false)`。
- 注释按钮始终可点击，通过 `commentExpanded` 独立控制展开/收起。
- 面板打开时跟随当前节点刷新内容；当前节点没有注释时显示“当前局面暂无注释”。
- 关闭按钮文案和无障碍标签同步为“收起注释”。
- 没有改动注释编辑数据、棋盘标注数据或保存链路。

## 验收

- `npx tsc --noEmit`：通过。
- `npm run build`：通过，产物约 4.87MB。
- 390×844 浏览器验证：打开注释后点击下一手，面板仍显示；切换到无注释局面，面板保留空提示；再次点击按钮后关闭；页面错误 0。
