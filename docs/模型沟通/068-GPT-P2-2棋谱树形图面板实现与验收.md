# 068-GPT-P2-2 棋谱树形图面板实现与验收

日期：2026-08-29

## 交接结论

P2-2 已完成首版并接入当前网页版：

- 地址：`http://127.0.0.1:5181/`
- 入口：记录模式 → 走棋 → “棋谱树”
- 实现文件：`src/tree-panel.tsx`
- 接入文件：`src/App.tsx`
- 样式：`src/styles.css`

## 已实现能力

1. SVG 棋谱树：节点、父子连线、当前路径和当前节点高亮。
2. 普通棋谱：显示根节点、当前路径及路径节点的直接变化；每个路径节点最多读取 12 个直接子节点。
3. 大型紧凑棋谱：通过 `compactChildWindow` 读取当前路径窗口，不使用 `Object.keys(document.nodes)` 枚举整棵树；可视预算 240 个节点。
4. 点击节点跳转：
   - 普通棋谱历史节点直接回看；
   - 直接变化复用现有分支选择和草稿主线记录；
   - 分页棋谱走已有分页导航；
   - DP/LIB 动态视图按深度回退或从分支点异步读取。
5. 缩放：65%–180%，支持缩小、放大和重置。
6. 拖拽：拖动画布查看较宽或较深的树；节点点击与画布拖拽已分离，避免微小位移吞掉点击。
7. 键盘：节点作为可聚焦按钮，支持 Enter/空格选择。
8. 视觉：沿用现有浅色/深色主题、绿色路径、高亮当前节点、黑白棋子标识；没有新增图表库或图片资源。

## 当前边界

- 当前首版是“当前路径附近”的可视窗口，不承诺在一个面板中一次展示百万级完整棋谱。
- 非当前路径的直接变化显示后续数量提示，暂不展开其全部后代；点击后会回到棋盘/分支导航继续读取。
- 没有新增动画库和第三方图表依赖，保持移动端包体和内存开销可控。

## 后续可选增强

- 视口内自动滚动到当前节点。
- 对隐藏子节点增加“展开此分支”按钮，而不是只在点击后回到棋盘。
- 若后续需要完整大谱浏览，可在当前窗口策略上增加按深度/按分支的渐进加载，而不是放宽全量物化预算。
