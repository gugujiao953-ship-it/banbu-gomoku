# 083｜读谱模式与棋谱库批量交互

日期：2026-08-30

## 本轮实现

- 新增 `AppMode` 的 `review` 只读模式，顶部模式顺序固定为“打谱｜读谱｜做题”。
- 读谱模式在数据命令层拦截 `play` 与草稿/元数据更新：只允许进入当前节点已有直接变化；叶子空位仅显示短暂提示，不创建节点、分支、草稿或脏状态。
- 读谱保留起点、上一手、下一手、终点、自动演示、棋谱树和已有分支导航；进入时终止 AI/分析线程并隐藏编辑入口。
- 棋谱库批量选择栏改为移动端固定底栏，补充全选/取消、移动、删除、更多和退出入口；删除使用二次确认。
- 统一状态栏模式控件支持 aria-label 与足够触控尺寸；结果 Toast 继续由统一计时器自动清理。
