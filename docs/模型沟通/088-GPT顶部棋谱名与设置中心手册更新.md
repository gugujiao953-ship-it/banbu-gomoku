# 088｜顶部棋谱名布局与设置中心、使用手册更新

日期：2026-08-31  
任务：修复手机端顶部棋谱名称重叠/左漂，并完成设置页与使用手册的本轮收口。

## 本轮完成

- 顶部统一状态区的棋谱名、图标、副标题和展开箭头改为固定 grid 列；棋谱名和副标题拥有独立的宽度、行高、溢出裁切规则，长标题不会侵入左侧图标、右侧箭头或下面的信息。
- 保留 `.workspace-current b` 兼容选择器，同时给标题增加 `unified-status-name` 专用类，避免旧样式影响新的状态区布局。
- 设置页删除旧的“设置”页眉，使用单一语义容器承载全部分类，避免 `display: contents` 和跨容器 CSS order 造成搜索、视觉顺序和键盘顺序不一致。
- 设置页新增偏好中心头部、设置搜索、分类命中计数和无结果状态；主分类均有 Lucide 图标，并按外观、思考、演示、显示、存储、数据和增强等优先级排列。
- 新增“外观中心”，集中主题、自定义背景、棋盘/棋子材质、棋子透明度、默认棋盘路数、音效和界面动效；已有配置均复用原持久化回调，没有新增危险的关闭项。
- 使用手册同步到当前产品：统一状态区、最近项目与恢复、读谱模式、棋谱树内分支复制/粘贴和书签、批量处理固定底栏、做题禁手/无禁手、规则说明、无限思考取消、最近导入、导出语义、资料安全边界、检查更新和设置搜索。
- 删除手册中已过时的“更多→查找/跨谱查找”入口说明，并如实注明自动快照、修改时间线和可选同步目前是底层能力，尚未宣称为完整云同步 UI。
- 设置回归脚本同步升级：验证旧“设置”标题消失、11 个分类、主分类图标、字号搜索自动展开、外观中心、手册/关于面板，以及 360/390/412px 顶部长标题布局。
