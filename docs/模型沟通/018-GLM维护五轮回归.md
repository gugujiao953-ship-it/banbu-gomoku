## 本轮维护中确认的最终架构

```text
RenLib 流
→ 列式数组解析
→ parent/firstChild/nextSibling/childCount
→ typed-array compact index
→ Worker transferable buffer
→ IndexedDB 分块保存
→ lazy document
→ compact 分支窗口
→ 增量棋盘缓存
→ React memo Board
```

大型文档不再经过：

- 数千万节点普通对象表。
- 每节点 RecordNode + children 数组。
- 大型 node Map。
- localStorage JSON.stringify 全量树。
- `Object.values(document.nodes)` 大型查询。
