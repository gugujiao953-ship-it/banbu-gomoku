# 076-GPT 标注最高显示层与原谱文字不叠加修复

日期：2026-08-29
状态：已完成

## 本轮用户反馈

1. 灰色变化点仍可能盖住棋盘原有标注。
2. 走到带原谱文字的着法后，原有文字被重复显示在棋子上。
3. 用户标注应处于棋盘内容的最高显示层，只有主动删除标注才消失。
4. 已有变化点必须继续保持节点优先点击，不能因为标注模式被改成普通落子。

## 根因

- 变化点冲突判断只覆盖当前节点的 `marks`，原生节点文字和原生节点标记没有统一纳入显示优先级。
- `Board` 曾将当前节点的 `boardText` 再次绘制在已落下的棋子坐标上，导致原谱文字看起来像附着在棋子上。
- 标注渲染位于临时候选/反馈提示之前，视觉层级不符合“用户标注最高”的产品语义。

## 修复

- 用户标注坐标会隐藏同点的变化灰点、原生变化文字和原生显式标记，但保留底部透明命中区，因此分支仍可点击进入。
- 删除当前着法节点上的 `boardText` → 棋子重复文字渲染；原谱文字只在未落子的变化点显示。
- 用户标注层移动到候选点、AI 推荐点和临时错误反馈之后、点击热区之前。
- 现有节点优先导航逻辑保持不变。

## 未改动边界

- 没有改变镜像/旋转逻辑。
- 没有改变已有分支树、编辑草稿和原始 LIB 的存储语义。
- 没有把原谱 `boardText` 擅自转换成普通用户标注。
