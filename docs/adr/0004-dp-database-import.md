# 0004 - DP/DB 私有棋谱数据库导入

**Status:** accepted
**Date:** 2026-08-27
**Spec:** 用户提供的 `九天指南v5-1.db` 样本
**Deciders:** 用户、Codex

## Context

用户提供的 `.db` 并非 SQLite，而是 LZ4 Frame 包裹的私有五子棋数据库。解压内容以 `@BTXT@` 分隔记录，坐标使用 `1–9/A–F` 两字符编码。项目需要让该样本可导入，同时不能把所有 `.db/.dp` 私有变体误称为一种公开标准。

## Decision

- `.db` 与 `.dp` 只进入专用二进制适配器，不回退为普通文本猜测。
- 支持标准 LZ4 Frame 的独立/关联区块、压缩/未压缩区块及可选校验段布局；损坏、截断和未知版本明确报错。
- 解压结果限制为 64MB，并校验区块声明尺寸，避免压缩数据使浏览器内存失控。
- 以 `@BTXT@` 为记录边界，提取行首两字符坐标；不足两步、重复落点或不完整记录不写入变化树。
- 有效记录从根节点合并为一棵 15 路变化树；同一前缀共享节点，可识别的文字保存在节点 `boardText`。
- 当前颜色按记录深度从黑棋开始交替。没有官方字段规范前，不推断样本中未确认的额外二进制语义。

## Consequences

- 用户提供的样本可在浏览器本地导入、保存、浏览分支，无需上传服务器。
- 不保证兼容其他软件或其他版本的同名扩展名；结构不符时明确拒绝。
- 若后续获得官方格式说明或更多不同样本，应扩展版本探测和字段语义，而不是放宽启发式猜测。
