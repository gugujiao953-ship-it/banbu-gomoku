### T1 · AI 棋力 P0：全尺寸 NNUE 引擎包 + YXBOARD 协议修复

- **状态**：✅ 已完成（代码 + 桌面验收通过；真机 / 群友实测待发布）
- **提交**：`44c2a7a`（随包 + 协议修复）、`097e550`（两档制应用内下载，用户决策）
- **背景**：群反馈「人机定式走不好、简单题解不开」。诊断（见 `docs/模型沟通/100`）：Rapfi 只用 92KB 玩具网络、无开局簿、做题走自研引擎。
- **方案（用户拍板两档制）**：
  - 默认随包**轻量引擎**（fallback 94KB），dist 回到 9.62MB、APK ~7MB。
  - **强力引擎包**（官方 mix9svq 冠军网络，覆盖连珠 / 无禁手 / 自由全部规则，47.4MB）改为**应用内下载**：设置「强力 AI 引擎」一键下载（进度条），下载完**下一次 AI 请求即生效，无需重启 / 配置**，可删除恢复轻量。
  - 取消中档（12–15MB 子集因网络按规则隔离，必然砍规则）。
- **关键改动**：
  - 引擎包出库：47MB 不进 git / APK，`engine-packs/rapfi-full-v1.data`（gitignored，SHA-256 `b3d7155b…714bf`），`scripts/repack-rapfi-data.py` 可复现。
  - 包存储 IndexedDB + 会话 blob URL；下载源 DEV 同源中间件 → 生产 Pages → Release 备用；远程源 `assertPublicHttpUrl` 严格校验（拒绝本机 / 内网 / 保留地址）。
  - worker：`analyze.dataUrl` + engine 门控；无 dataUrl 一律 fallback；`deviceMemory<2GB` 真低内存机即使装包也走轻量；30s 超时 / 失败自动回退。
  - **YXBOARD 协议修复**：rapfi 颜色字段是 SELF/OPPO（相对引擎）+ 黑先世界 + 自动 Pass；旧 worker 按绝对色发送导致**白先题整盘颜色镜像**。新增 `canonicalBoardMoves` 规范编码（黑先交替列表零行为变化）。
- **验证**：
  - engine-pack 单测 8/8（URL 校验 / 截断拒收 / 换源重试 / 重启恢复 / 删除）。
  - vitest 全量 359/359；run-qa browser 全绿。
  - 端到端 `scripts/verify-engine-pack-ui.mjs` 全通：下载 → 生效 → worker 经 blob URL 加载 full 仅 379ms。
  - 基准（三手胜4-高级题 30 题 @1800ms 连珠）：fallback 26/30 vs full 25/30（短时限战术转换等效，剩余失败为题位结构性非强制胜，6s 重测仍不解）；同局面对照 full −11 / 0.486 / depth14 vs fallback −107 / 0.369（着法合理性与评估校准差异可见）。
