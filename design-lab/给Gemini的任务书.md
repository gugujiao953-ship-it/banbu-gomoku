---

你好，请帮我重新设计一款**五子棋/连珠打谱软件**的界面外观。附件 `gomoku-design-lab.html`
是一个自包含的沙盒预览页：里面用真实的 CSS 变量还原了软件 20 套主题和当前主要界面的
结构与观感（顶部工具栏、棋谱库文件夹与棋谱卡、题库题集卡与管理面板、设置页开关与音色选择、底部导航）。
页面顶部有主题与字号切换器，请你改完后在这些主题下自检。

## 你能改哪里（重要）

文件里的 CSS 分成四个区块，有注释标明：

- **区块 A 主题令牌** —— ❌ 禁止修改。这是软件 20 套主题的颜色来源，全部配色必须引用这些变量。
- **区块 B 沙盒骨架** —— ❌ 不要动（外框、切换器）。
- **区块 C 现有组件外观** —— ✅ 可以重新设计：改这里等于改软件现状。
- **区块 D「追加区」** —— ✅ **推荐**把你新增/覆盖的规则全部写在这里，方便回传后快速比对。

DOM 结构和类名与真实软件一致，请**保留类名与嵌套结构**（视觉可自由重做：间距、圆角、
边框、阴影、字重、层级、装饰元素）。若确需改结构，请在回复里单独说明改了什么类名。

## 设计目标

1. 整体气质：**现代但不冰冷，有东方棋具的质感与书卷气，克制、精致、留白得当**；避免厚重拟物和廉价大圆角卡片风。
2. 重点对象（优先级从高到低）：
   - 题库「题集卡」与「管理面板」（层级、进度信息呈现、题号与把手的观感）
   - 棋谱库「文件夹头 + 棋谱卡」（信息密度、选中/悬浮反馈的暗示、缩略图与文字的节奏）
   - 设置页（开关、音色选择块）
3. 深色主题必须和浅色主题一样精致（软件大多数用户使用深色主题）。

## 硬性约束（违反将被退回）

- 只用区块 A 的语义变量配色（`--surface / --surface-2 / --surface-3 / --paper / --ink / --muted / --line / --surface-border / --jade / --green / --green-2 / --gold / --red`），**不得新增硬编码颜色**；唯一例外：棋盘缩略图（.mini-board）的木色与黑白棋子色可以保留。
- 所有文字对比度 ≥ 4.5:1（次要文字也不能靠"白底白字"式变浅）；任何主题下不得出现"白得发光"的孤岛或看不清的次要文字。
- 字号保持小（正文 9-13px 区间）但行高充足；中文不换行的控件/标题用省略号；移动端 390px 宽度不溢出。
- 保留触摸友好：可点控件 ≥ 28px 高；拖拽把手（.grip）明确表达"可拖"。
- 不引入外部字体/图标库（现网环境为系统字体；表情符号图标可替换为 CSS 绘制，但不得引用网络资源）。
- 单文件交付：只改 `<style>` 与必要的少量 DOM，不拆分文件。

1. **完整的修改后 HTML 文件**（可直接双击预览的）；
2. 一段简短的设计说明：改了什么、为什么、在哪些主题下你最得意。

先给我一个方向探索稿（可以大胆些），我确认方向后你再细调。
