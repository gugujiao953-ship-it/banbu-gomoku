FIG.02 —— 打谱与变化
01

打谱与记谱流

点空位落子、点棋子跳手；上/下一手、到首尾、90° 旋转与左右镜像。新增的记谱流是默认页：主线横排、变化缩进，主分支可以「设为 / 在这一支 / 切回」。画布降为「图谱」标签页，默认只画当前路径加一条最长分支，分支点标数量、可展开收起。

BOARD5–22 路棋盘 · 缩放上限 2.35 → 6 倍 · 放大后可平移
LONG长按环形菜单：内环切页、外环六槽固定
RULE无禁手 / 有禁手，禁手点实时提示
02

导入与导出

SGF、RenLib 的 LIB 大型开局库、DP 分页谱、DB 索引、JSON、POS、ZIP 以及 SGF 同族扩展名照收。安卓上微信、QQ 或文件管理器里点棋谱，选「用半步打开」就进应用，一次可以选多份，冷启动也接得住。

FIXED中等体积棋谱导入必失败、大 SGF 被存成空谱 两处修掉
THREAD解析移出主线程，读长谱不卡界面
EXPORT默认写进「下载」夹、可自选位置，设置里显示占用空间
03

识谱：先核对，能改子，再导入

识别完不再直接建谱，而是停在核对屏：识别出的子按识别到的网格画成半透明圆圈叠在原图上，网格线一并画出来，顶上写明共几子（黑几 / 白几）与置信度，多子、少子、黑白反了、整体错一格都看得出来。看法有四种：叠图 / 只看原图 / 只看识别 / 编辑。进编辑模式后点交叉点就能改颜色、去子、补子，整盘还能上 / 下 / 左 / 右挪一格；挪出棋盘会被明确拒绝，不会悄悄裁掉。核对完点「确认导入」，才生成一份未保存的棋谱。

FIXED选图入口默认停在本机相册（这行接线早前丢过一次）
PERF大图预览降采样到 2048px 以内，核对屏不再卡
EXTRA「复原手序」按棋子序号重建落子顺序，实验开关默认关闭
04

本地 AI 分析

旗舰引擎 KataGo 随包自带、本机原生运行：b10c128 小网 3.2MB、b24c256 大网 21.9MB，装好就用，不用下载。面板分「计算 / 复盘 / 胜率」三页，游标竖线跟着棋盘当前手走，点图能跳回那一手。分析过的局面会落进缓存，重开棋谱可以载入上次结果。

BG切到后台引擎真的停下，回前台自动续上
READOUTKataGo 看黑（白）方胜率 · 和棋率 · 访问量 · PV
CLOUD可填自己的 iKataGo 服务器，只接管分析
05

人机对弈 · 独立一屏

对弈不再寄生在打谱页：自己的界面，有双方信息格、我方时间、回看 / 悔棋 / 认输 / 重开、最近几手与独立终局面板（写清胜负原因）。中途退出，下次点「开始对局」会问要不要接着上局下。终局默认不自动进棋谱库，要不要存由你决定。

LEVEL初级 0.6s / 中级 2s / 高级 5s / 大师 10s / 自由
SHOWN只显示哪台引擎、算到第几层、看了多少节点
HIDDEN对局中不显示推荐点与胜率，防剧透
06

战绩与等级分

每一局自动记在本机：六格概览（场次 / 胜负和 / 胜率 / 连串 / 平均手数 / 累计用时）、逐局折线、难度×引擎分档表与最近 10 局。等级分锚的是自家 AI 档位（初级 = 1000 分、每档 +240），面板里写明这是假设不是实测。

LOCAL账本只存这台设备，上限 400 条，换机或清数据会丢
STATE样本 < 10 局标「定级中」；0 局也不塌成空态卡
VCFVCF 那一页这版是占位，一格假数字都不放
07

整局复盘

一局下完能看逐手评估曲线、失误分档（最佳 / 疑问 / 失误 / 败着 / 错失必胜）、最差三手与可复制的中文讲解词；预算分快 / 标准 / 深。每手读秒、终局自动存档，「复盘本局」一键跑。

CURVE游标竖线与棋盘双向联动，带刻度轴
FIXED胜率黑白颠倒按必胜局面在真机标定后修掉
TEXT讲解词可直接复制出去
08

题库训练与线下棋钟

VCF 出题生成器（变形 / 原创），做题时点分析就是「帮你想一手」并直接落子；题库管理补齐单题增删改、题集合并与拆分、隐藏内置题集，「已掌握」与「做对」分开计。另有一个整屏的比赛计时器，线下摆真实棋盘也能用。

CLOCK菲舍尔加秒 / 布龙斯坦延时 / 包干 / 读秒 四种计时制
PRESET按连珠正式赛时限排（含世锦赛 2 小时 + 30 秒）
EXP在线棋谱库与自建题库是实验开关，默认关闭
