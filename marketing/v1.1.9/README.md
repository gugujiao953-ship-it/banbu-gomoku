上一版生产目录是 `marketing/v1.1.8/`（含 `site/`、`stills/`、`seq/`、`tools/`、`video/`、`dist/`）。
本版**只做宣传页**，没做视频与截图序列，所以目录小得多；视觉语言（黑金配色、字体栈、区块顺序、

## 怎么本地打开看

**方式 A —— 直接双击**（页面不引任何外部文件，棋盘画面全部是内联 SVG 现场绘制）：

```
双击 marketing/v1.1.9/site/index.html
```

**方式 B —— 静态服务器 + 自检**（端口自己挑，别占别人在用的；下面用 3911）：

```bash
cd marketing/v1.1.9/site && python -m http.server 3911 --bind 127.0.0.1 &
node marketing/v1.1.9/tools/selfcheck.mjs          # 重跑自检并重写两张 preview-*.png
node marketing/v1.1.9/tools/检查-本地直开.mjs        # file:// 离线直开检查
node marketing/v1.1.9/tools/检查-类名冲突.mjs        # CSS 类名撞车检查
```

`selfcheck.mjs` 读 `SELFCHECK_URL` 环境变量换端口，默认 `http://127.0.0.1:3911/`。
末行打印 `=== 汇总问题数：0 ===` 才算过。

## 文案来源与口径

- **权威来源是仓库里的三份文件**，不再拿 `artifacts/releases/1.1.9/*` 当依据：
  `docs/1.1.9-增量清单-v1.1.8.1到1.1.9.md`（分组增量 + 数字口径表 + 不许宣传清单）、
  `docs/1.1.9-发布正文.md`（GitHub 正文，引擎在前）、`src/release-notes.ts` 的 `"1.1.9"` 条目（应用内 16 条说法）。
  页面可以比应用内更丰富，但**不能与应用内矛盾**。
- 基线是**线上 v1.1.8.1**（不是上一个提交）：中间 1.1.8.2 … 1.1.8.21 从没发布，所以这一版对用户是两个月的量，
  页面在 HERO 与 `L-16` 都写明了这个跨度。
- 已核实并写进页面的硬事实：**1.1.9 的 APK 里没有任何 KataGo / ONNX Runtime 文件**（`unzip -l`，只有
  `librapfi-engine*.so` 与 wasm）、**1.1.9 / versionCode 63 / tag v1.1.9 / `banbu-gomoku-1.1.9-android-release.apk`**、
  大网 int8 **21.9MB**（替换 fp16 **42.4MB**）、rapfi 原生 **0.43.02**、棋盘材质 **14** / 棋子材质 **16**（`src/features/manual/sections/ch16-appearance.ts`）、
  落子交互 **11** / 棋子进场 **12**（`src/appearance/effects.ts`）、识谱核对屏四种看法与可编辑动作
  （`src/features/record/image-verify.tsx`，门禁 `scripts/ui-recognition-verify-check.mjs`）。
- **不编数字**：APK 最终体积与 SHA-256 现在不存在 → 一律写 `<待填：打包后>`（见 `发布后要改的占位.md`）。
  「约 80.1MB」是口径表里 1.1.8.21 的实测值，页面上**明写了是估、以打包产物为准**。
  反面教材是 v1.1.8 页面里没跟着版本更新的 `versionCode 27` 与 `45.78 MB`。
- 速度类只有两条被允许写：**1.95×**（int8 vs fp16）与 **2.15×**（旗舰引擎解锁），
  每一处都带「同一台测试机（Redmi K20 Pro / 骁龙 855）、同局面、限预算」与「你的设备会不同」。
  不利说明照实保留：int8 只跑了 4 局 2:2、没跑大样本；VCF 面板是占位；战绩只存本机不能同步；
  云端只接管分析；KataGo 只支持 15 路以内；大网更慢更耗电。
- **两条红线**：① 不宣传 ONNX / 本地模型识谱（工作树里没有它的落地证据，用户也确认那个约 19MB 的识别模型因效果不好被放弃），
  识谱在页面上只指「图片识别 + 可编辑核对屏」；② 内部工装（门禁条数、机械生成脚本、常量 bump）不进页面。
- 页面里的棋盘与胜率曲线是**内联 SVG 示意图**，页面上已写明「非应用截图」，不冒充实拍。
