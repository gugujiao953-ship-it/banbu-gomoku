# 半步五子棋 1.1.9 宣传片创作提示词 v2

制作一支约 78 秒、1920×1080、30fps 的「半步五子棋打谱 1.1.9」产品发布片。它必须是一支真正重新设计的 AE / Apple 产品发布片：以当前 `1.1.9.6` 应用真实截图和真实交互为主体，旧版 v1.1.8 的黑金翡翠配色、手机壳三卡、底部胶囊字幕、慢速浮动镜头、旧文案和旧素材全部淘汰，只把旧工程的逐帧渲染技术当作参考。

## 核心概念

片名：**《把下一手看清》**。

一颗黑石贯穿全片：它从棋盘落下，展开分支树；变成识谱核对的校准点；沿 VCF 正确路线前进；进入 KataGo 的搜索核心；在 AI 对弈中落定；最后回到应用图标。观众看到的是一条连续的研究链，而不是功能截图列表。

## 视觉系统

- 纸白 `#F4F2EB`、碳黑 `#0B0D12` 两种主场景，电光钴蓝 `#145CFF`、朱砂红 `#FF4C3D`、酸橙 `#D9F24A`、紫 `#8C6CFF` 为功能状态色。
- 禁止旧版金色、翡翠绿色主导，禁止三枚大径向光斑，禁止旧手机壳和厚重黑金舞台。
- 真实 App 画面作为无装饰平面窗口嵌入 15×15 棋盘坐标空间；窗口只保留细边、局部裁切和真实内容，不伪造 UI。
- 标题使用极粗无衬线大字，等宽字体用于坐标、节点、引擎读数。屏幕内标题取代底部字幕胶囊，底部只保留 2px 进度线。

## 动效规则

- 所有动画由 `renderFrame(t)` 逐帧确定性计算，禁止 CSS animation / transition 作为主动画，禁止不可复现随机数。
- 使用 3D 透视轨道、SVG 15×15 网格、路径描边、clip-path 切片、遮罩、吸附、硬切、路径擦除、镜头穿越和微回弹。
- 以 112 BPM 对齐：四分音符 `0.535714s`，半拍 `0.267857s`；大镜头在小节点，小元素在半拍点。
- 统一转场库：镜头穿越交叉点（0.45s）、路径擦除（0.30s）、四切片同步（0.54s）、色面硬切（0.27s）。每个转场只使用一个主效果。
- 粒子只围绕棋子、路径和搜索树生成，数量控制在 100–150，不能铺满屏幕。石子落点需要有重量、冲击波和短暂回弹。

## 时间轴与文案

1. **0:00–0:04 冷开**：空棋盘，黑石垂直落下，冲击波画出坐标网格。文案「别只落子。把下一步看清。」
2. **0:04–0:11 打谱与变化**：当前 1.1.9.6 打谱页进入棋盘平面，主线、分支、书签被路径描边。文案「从打谱开始，走进每一种可能。」
3. **0:11–0:17 多格式导入**：SGF / LIB / DP / DB / JSON / POS 字标沿轨道吸附到真实导入页。文案「来自哪里，都能接住。」
4. **0:17–0:24 图片识谱**：原图、对齐、识别、叠图核对、编辑五态切片匹配；错误棋子朱砂抖动，修正后酸橙校准。文案「照片不是终点。核对、修正、复原，整盘回来了。」
5. **0:24–0:31 VCF 与题目生成**：当前 VCF 挑战与棋题生成器并置，错误路线碎裂，正确路线钴蓝/酸橙吸附。文案「把胜势练成反射。」
6. **0:31–0:42 本地引擎**：搜索树从棋盘候选点爆发，切入真实 KataGo 设置与分析画面，露出 b10c128、b24c256 int8、21.9MB、线程可调和 Rapfi 0.43.02。文案「旗舰引擎，随包而来。离线，也能深算。」
7. **0:42–0:51 AI 对弈**：真实专门对弈页全画面，难度轨道初级→进阶→大师，思考光标和真实落子完成 match cut。文案「AI 不在后台。它就在这盘棋里。」
8. **0:51–0:58 外观**：不做旧版三卡主题墙；同一块真实棋盘通过整屏色面切片切换主题与棋子材质。文案「20 套外观，让每一局都有气质。」
9. **0:58–1:05 后台恢复**：思考中的真实画面冻结成时间轴，拉远到系统背景，再由同一手棋和读数吸回对弈页。文案「切到后台，棋局不会掉线。」
10. **1:05–1:13 学习链**：导入、识谱、打谱、分支、VCF、分析、对弈沿棋盘边缘逐个点亮，路径汇成图标。文案「打谱、做题、分析、对弈，一条学习链。」
11. **1:13–1:18 收束**：路径收成黑石，黑石落入真实图标。大字「半步五子棋打谱 1.1.9」，副句「给每一手，留下答案。」

## 真实性边界

- 所有 UI、按钮、引擎读数、难度、题库和识谱状态必须来自当前 1.1.9.6 实际运行画面。
- 允许抽象化棋盘路径、搜索树、粒子和转场，但不得生成不存在的产品按钮或虚构数值。
- 不宣传 VCF 等级分的假数据；不把云端引擎说成人机对弈引擎；不声称识谱准确率提升。
- 输出 `promo-v2.html`、逐帧渲染脚本、程序化配乐、SRT、MP4，并对 0/24/42/58/78 秒关键帧检查无空屏、无重叠、无旧版风格残留。
