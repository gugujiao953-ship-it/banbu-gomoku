# 半步五子棋

移动优先的五子棋 / 连珠打谱与做题工具。当前版本以 React + TypeScript 实现共享核心，通过 PWA 提供离线网页版，通过 Capacitor 提供 Android 应用；未来桌面端可继续复用相同的棋谱模型与格式层。

> 这是一个 Vibecoding 的产物，也是一款永久免费、开放源代码的软件。希望它能让手机打谱和做题更方便；如有内容涉及侵权，请通过 GitHub Issue 联系，我会及时处理或删除。

项目仓库：[github.com/gugujiao953-ship-it/banbu-gomoku](https://github.com/gugujiao953-ship-it/banbu-gomoku)

桌面参考软件的功能拆解与移动端迁移决策见 [DESKTOP_REFERENCE_AUDIT.md](./DESKTOP_REFERENCE_AUDIT.md)，开宝 APK、题库和 SlowRenju 引擎的审计见 [KAIBAO_REFERENCE_AUDIT.md](./KAIBAO_REFERENCE_AUDIT.md)。

## 已实现

- 15×15 棋盘，手机触控落子，点击已有棋子跳转到对应手数
- 棋盘四边固定显示 A–O / 15–1 坐标，支持显示/隐藏、旋转 90° 和左右镜像
- 完整变化树：创建分支、设为主线、删除当前变化及其后续
- 变化面板显示分支后续坐标预览，并提供“回到分叉支点创建变化”
- 改着模式：选中当前手后点棋盘空位替换坐标，保留后续变化
- 候选点模式：A–E 局面标签，节点级保存并以 SGF `LB` 交换
- 局面分析：按成五、活四、冲四、活三和防守点给出可解释的候选排序（明确不是完整 VCF/VCT 证明器）
- 起点、上一手、下一手、终点导航，支持外接键盘左右方向键
- 当前棋谱内查找坐标、手数、节点注释、局面文字与着法评价，结果可直接跳转
- 节点注释、局面文字，以及好手 / 坏手 / 疑问手 / 趣着 / 胜着 / 唯一手 / 研究点评价
- 独立棋盘标注：1–9、胜 / 败 / 平 / 平衡、攻守提示、A–E、自定义文字，以及长按圆圈 / 三角 / 叉号
- 连珠黑方常见长连、四四、三三禁手辅助提示（研究模式不阻止落子）
- 本地棋谱库和约 0.5 秒防抖自动保存
- 棋谱库按棋谱名、棋手、赛事主题即时检索
- 最多 50 份棋谱批量导入；LIB 单文件最大 200MB，全部由 Worker 流式读取；大型 LIB 以紧凑索引存入 IndexedDB，启动时只读摘要，点开后按需恢复节点
- 普通与大型棋谱均处理内容重复和 ID 冲突，并隔离单文件失败
- 规则、棋手、赛事、日期等棋谱信息
- 可安装 PWA、离线缓存、安卓安全区和竖屏适配
- 单棋盘工作区：打谱 / 做题是同一棋盘的行为状态，翻面时完整保留原棋谱会话
- 当前棋谱 / 题目栏可点击切换；题集、题号、搜索、先手与完成状态集中在同一选择器
- 行棋、研究、记录、应战、选题和视图收进可折叠上下文工具坞
- 做题初始盘面与尝试历史分离；悔棋回退一人一机，重启只恢复本题初始局面
- 玩家落子后由独立 Web Worker 陪练应对，支持强制停止且旧任务不能回写新题面
- 棋盘页上一题 / 下一题、题集文件夹、完成进度和导入题集持久化
- 兼容开宝二维 JSON 题库：星级、空占位、A–O / 1–15 坐标和黑白尾码
- 本地构建按用户提供的 APK 接入开宝 8 套有效题库 433 题，连同 3 道体验题共 436 题

## 文件兼容

已支持导入：

- `.sgf` / `.fgf`：SGF FF[4] 游戏树、注释、节点名、常用标记、着法评价和基础元数据
- `.pos` / `.txt`：`h8i8h9`、`H8 I8 H9` 形式的坐标序列
- `.ren` / `.renjs` / `.wzq`：内容为 SGF 语法时可直接读取
- `.renju` / `.json`：本软件完整跨端数据格式

已支持导出：

- `.sgf`：用于与 RenLib、其他棋谱工具交换
- `.renju`：完整保存变化树、注释、标记和元数据，供未来三端互通

`.lib` 是 RenLib 的二进制变化树格式。当前版本已支持现代 `RenLib 3.x` 头、旧版无头文件、主线/分支控制字节、常见节点注释、节点文字和标记位；所有 LIB 均在后台线程流式解析，4MB / 4 万节点以上以紧凑索引进入 IndexedDB 大型棋谱库。纯浏览不会把索引重新膨胀为完整对象树；首次编辑大型棋谱时会安全物化为普通文档后保存。遇到超出 3.4 的版本会明确报错，不会静默损坏棋谱。

`.txt` 不是统一的五子棋专有格式，本项目只把它作为 `H8 I8 H9` 一类纯文本坐标序列的兼容入口。JSON 分为棋谱库使用的 RENJU 完整变化树与题库页使用的开宝兼容题集数组，两者会分别校验。

## 本地开发

```powershell
npm install
npm run dev
```

生产构建和测试：

```powershell
npm test
npm run build
```

## Android

项目已包含 `android/` Capacitor 原生工程。

```powershell
npm run android:sync
npm run android:open
```

命令行构建 debug APK：

```powershell
cd android
.\gradlew.bat assembleDebug
```

需要 JDK 21、Android Studio / Android SDK，并正确设置 `JAVA_HOME`。APK 通常输出到 `android/app/build/outputs/apk/debug/app-debug.apk`。

## 视觉验收

```powershell
node .\qa\mobile-visual.mjs
```

脚本使用 Playwright 在 360×800 和 412×915 触控视口下实际落子，并验证坐标、改着、变化、候选点、局面评价、查找、批量导入、重复去重、页面宽度与棋谱库，最后生成 `artifacts/` 截图。
